## 一句话概括

CARGO 面向混合交通下的匝道汇入场景，先用因果推断分清"谁影响了谁、谁该为风险负责"，再按各车的责任大小做有针对性的安全策略修正。

## 核心方法

- **带不确定性的交互图**：从历史轨迹推断一个共享的隐含交通上下文，用来区分"车 A 真的影响了车 B"和"两车只是一起对下游拥堵做出反应"。影响边按置信度筛选，推断不可靠的边会被剔除。
- **功劳与责任分开算**：功劳方面，把"影响强度"和"对团队收益的边际贡献"结合起来做奖励塑形，奖励真正帮到队友的车；责任方面，用条件扩散模型生成未来响应，估计某个动作相比安全参考策略多出来的尾部风险（CVaR），以此认定"可避免风险"的来源。
- **按责任做预防式修正**：责任越大的车，要求降低的风险越多，但不超过它在信任域内实际能调整的幅度。更新时预留安全余量，并对所有车的安全约束做联合可行性检查；不满足就把策略投影回安全区域。

## 关键结果

- 在 highway-env 的低、中、高三档车流密度下做了评测，另外还有因果图恢复和归因准确性的受控实验。
- 高密度场景下，成功率比各指标上最优的基线高 66.04%，碰撞率降低 56.23%。
- 理论上证明了在给定假设下风险单调下降，并给出环境回报不下降的局部充分条件。

## 为什么值得关注

多智能体安全 RL 常把代价平摊，或直接惩罚"出事的那辆车"，可承担风险的车不一定是风险的源头。CARGO 把"分清因果责任"和"保证修正能共同实现"串成一条完整的流程，对自动驾驶编队、多机器人协作这类多方共担风险的场景有参考价值。不过实验只在仿真环境里做，真实交通中能否泛化还需要验证。

## 一句话概括

把 PIV（粒子图像测速）里"相机放哪儿"变成一个闭环决策问题：机械臂上的相机由强化学习策略控制，自己去找、对准并拍清水翼尾流，策略只在仿真里训练，直接零样本迁移到真实水洞。

## 核心方法

- **任务建模**：把相机摆位建模为 POMDP。智能体看不到真实流场，只能看到 LIMA（轻量 CNN 光流/PIV 估计器）从图像对中算出的速度场、速度亏损和不确定度，然后输出相机在笛卡尔空间里的目标位置 (x, y, z)，再经标定换算成 6 自由度机械臂的关节角。
- **仿真训练**：用 Isaac Sim/Isaac Lab 搭了一个照片级的水洞数字孪生，光片、示踪粒子、镜头光学都有建模；尾流来自不同 NACA 翼型、位置、攻角和来流速度下的 CFD 结果。智能体用 DreamerV3 训练。
- **sim-to-real 思路**：策略的输入是光流估计结果而不是原始图像，对外观差异基本不敏感，再配合域随机化；同时保留估计器本身的误差（比如阴影区域的伪流动），让策略在训练中学会忽略这些区域。

## 关键结果

- 不做任何真机微调，策略在真实水洞里就能稳定找到随机摆放的水翼尾流并完整框住。
- 和固定视角相比，尾流分辨率更高，测得的流动统计量误差更低。
- 测量质量接近"全场扫描+拼接"，但时间只要大约一半，图像对数量也少得多。

## 为什么值得关注

这是把主动感知和 RL 用到实验流体测量上、并在真实硬件上跑通的一个案例：RL 不是拿来控制流动，而是用来改进"怎么观测流动"。"用任务相关的中间表示（光流）作观测"这个零样本迁移办法，对其他依赖昂贵物理实验的科学仪器自动化也有参考价值。

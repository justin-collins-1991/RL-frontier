## 一句话概括

移动机器人推拉椅子、推车这类大件物体时，"抓哪儿"会直接决定最后能不能摆到位。Grasp-TAGS 把 RL 训练出来的价值函数（critic）蒸馏成一个轻量的抓取打分网络，在手碰到物体之前就挑出对当前目标最有利的抓取点。

## 核心方法

- **统一策略**：用 PPO 训练一个同时以目标位姿和初始抓取为条件的移动操作策略，训练时覆盖多个候选抓取（如椅背、左/右扶手）。这样 critic 自然学会了"从不同抓法出发，后续任务能做多好"。
- **Critic 蒸馏**：critic 需要交互过程中的完整观测，没法在接触前直接用。作者把它的估值蒸馏到一个小网络里，输入只有候选抓取配置和目标信息。
- **推理流程**：对所有候选抓取打分，选分数最高的那个，再交给统一策略去执行。

## 关键结果

- 仿真中多种大型家居物体的目标位姿重排任务：平均成功率 89.84%，而表现最好的固定单抓取策略为 79.87%，提升约 10 个百分点；同时也优于随机选抓取。
- 在所有评测物体上，最终朝向误差都有所下降。

## 为什么值得关注

以往基于学习的移动操作工作大多默认初始抓取是固定的，这篇论文说明，几何上同样稳定的抓取，对下游任务的效果可能差别很大，因此抓取应当按任务来选。另外，"复用 RL 训练副产物 critic 做前置决策"这一思路成本很低、容易迁移，也适用于其他需要在执行前选初始条件的长时程任务。不过目前只有仿真验证，真机效果还有待检验。

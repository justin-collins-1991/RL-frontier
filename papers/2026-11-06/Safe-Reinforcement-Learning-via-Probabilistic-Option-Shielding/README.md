## 一句话概括

把只看下一步的概率逻辑护盾（PLS）提升到"选项"（多步宏动作）层面，用一个免模型学出来的安全评论家估计整段选项安全执行完的概率，从而在不需要完整环境模型的前提下获得长程安全性。

## 核心方法

- **问题**：传统护盾依赖完整环境模型；PLS 用概率逻辑程序给每个动作打安全分，不需要模型，但只顾眼前一两步，看不到"现在加速、待会儿刹不住"这类延迟后果。
- **思路**：在分层 RL 中，高层策略选择选项并持续执行到终止。POS 把"整个选项全程安全的概率"作为护盾信号，按 PLS 同样的方式重加权高层策略：越可能出事的选项被选中的概率越低，且整个过程保持可微。
- **怎么估计**：选项安全概率可以写成类似价值函数的递推式，作者证明在选项时长有上界时存在唯一不动点。实际中用 TD 学习训练一个安全评论家（表格或神经网络，可预训练也可与策略同步更新），监督信号直接复用 PLS 已算好的单步安全概率，不额外增加逻辑推理开销。
- 单步动作可视为长度为 1 的选项，因此 PLS 是 POS 的特例。

## 关键结果

在 LogiCity 城市导航任务（含军事禁区、上学时段行人等安全约束，包括随机地图）上，POS 训练过程中的违规明显少于单步 PLS 和其他安全 RL 基线，同时任务回报与它们持平。

## 为什么值得关注

它给"免模型"和"长程安全"之间的取舍找到了一个实用的折中：安全知识仍由可解释的逻辑程序表达，长程后果交给 TD 学习去估计。对自动驾驶、机器人这类"训练期就不能乱试"的场景，以及神经符号与分层 RL 的结合，都有参考价值。局限是选项集合需事先给定，且只在 workshop 规模的网格环境上做了验证。

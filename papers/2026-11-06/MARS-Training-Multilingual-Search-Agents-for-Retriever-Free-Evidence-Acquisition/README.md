## 一句话概括

MARS 不用向量检索器，让大模型直接写 shell 命令（如 `grep`）去搜多语言原始语料。作者用强化学习训练这个智能体，解决跨语言实体名对不上、搜索动作重复这两个问题。

## 核心方法

- **直接语料交互（DCI）**：每轮先推理，再选一个目标语言语料库，然后生成可执行的搜索命令。检索结果返回给模型后，模型自己决定是改写查询、换语料库，还是直接回答。整个过程不需要建 embedding 索引，也不依赖相似度排序。
- **语料原生实体锚定**：精确匹配对实体写法很敏感，比如 "Cristiano Ronaldo"、"C罗"、"克里斯蒂亚诺·罗纳尔多" 都指同一个人。MARS 会从检索到的"实体介绍型"段落里抽出该语言的标准名和别名，作为锚点回填给模型。如果某次没搜到结果，就退到英文语料先查一次，再拿到目标语言的写法。
- **冗余感知搜索奖励**：在 GRPO 基础上做了改进（URPO）。除了答案对错的奖励外，再按轨迹里不重复命令所占的比例给额外奖励，命令之间的相似度用 Jaccard 衡量。这样可以抑制模型反复发同一条命令，缓解多语言 RL 训练崩溃的问题。

## 关键结果

- 效果稳定超过基于检索器的多语言 RAG 基线和已有 DCI 基线。
- 在训练见过和没见过的语言上都能迁移。
- 在稀疏 EM 奖励下训练依然稳定，而现有多语言 agentic RAG 基线在这种设置下会崩溃。
- 无效、重复的语料交互明显减少。

## 为什么值得关注

它说明"让模型自己写 grep"可以替代多语言检索器，省掉了建索引和维护的成本，也绕开了跨语言 embedding 分布偏移的问题。另外，用"搜索简洁度"这种轻量的过程奖励来稳住多轮工具调用的 RL 训练，这个思路可以推广到其他 agentic 搜索场景。

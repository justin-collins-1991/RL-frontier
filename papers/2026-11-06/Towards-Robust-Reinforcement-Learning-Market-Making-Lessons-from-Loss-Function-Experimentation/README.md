## 一句话概括

在强化学习做市里，只追求利润的损失函数会让智能体"躲着不交易"；加上库存过高、现金过低的惩罚后，策略反而更赚钱、也更稳。

## 核心方法

- 环境：用几何布朗运动模拟股价，买卖方报价围绕上一时刻价格随机生成；智能体每步输出下一轮的买价和卖价。
- 模型：actor-critic 架构，actor 是三层全连接网络，输入历史报价、利润、库存和现金。
- 对比两种损失：① 纯利润；② 利润 + 现金低于下限的惩罚 + 库存超过上限的惩罚（按市值计）。
- 每回合最多 200 步，现金耗尽或库存为负就提前结束，一共训练 400 回合。

## 关键结果

- 带惩罚的版本累计奖励明显更高，每回合奖励也更稳定。
- 纯利润版本经常拿到 0 奖励：它学会把买卖价差拉得很宽，故意不让交易发生，用来规避亏损。
- 带惩罚的版本价差更窄、波动更小，刚开始容易提前出局，训练后能坚持的步数越来越多。

## 为什么值得关注

它用一个很直观的实验说明：做市 RL 里风险约束不只是"保守的代价"，还能当作有用的塑形信号，防止策略退化成"不交易"。不过实验比较简单：只有模拟环境、两种损失、单一配置，没有真实行情和基线对比，结论更适合当作设计奖励时的经验参考，不宜直接当成定论。

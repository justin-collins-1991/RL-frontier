## 一句话概括

在基于评分细则（rubric）的 RL 中，组内全部失败或全部通过的评分项不产生梯度信号。RuACT 给这两类"失效"评分项分别安排"老师"和"评委"的角色，把这部分监督重新利用起来。

## 核心方法

- **问题**：GRPO 看的是组内相对优势。某条 rubric 如果所有回答都没满足（不可达）或都满足了（饱和），它对每个回答的贡献相同，会被直接抵消。在 Qwen3-4B 医疗训练里，这类观测占 60.88%，调权重也救不回来。
- **诊断**：不可达项缺的是"行为"。把 rubric 写进 prompt，满足率就从 1.13% 升到 91.25%。饱和项缺的是"区分度"：回答都过了，但质量其实还有高低。
- **Rubric as Teacher**：把不可达的 rubric 拼进 prompt，交给冻结的自身模型当老师。在组内最佳回答的前缀上，用 token 级前向 KL 把老师的分布蒸馏给学生。加了一道奖励门控：只有带提示生成的回答总分超过所有普通回答时才做蒸馏，防止为了这一项牺牲其他项。
- **Rubric as Critic**：把饱和 rubric 拆成更细的子 rubric，只保留能拉开当前回答差距的那些。子项共享父项的权重，所以原始优化目标不变。

## 关键结果

- Qwen3-4B 上，在 4 个医疗/科学基准上全部超过 GRPO、rubric 重加权和 rubric 引导探索。提升最大的是 ResearchQA，从 64.82% 到 69.44%。Qwen3-1.7B 上平均分最佳。
- 对最初不可达的 rubric，不加提示时的满足率从 35.02% 升到 42.86%。
- 子 rubric 让奖励与独立评审的一致性从 57.74% 升到 60.77%，换一个评审模型结论依然成立。

## 为什么值得关注

rubric RL 是把 RLVR 推广到开放式任务的主流做法之一，而一半以上的评分信号一直在被白白浪费。这篇论文先诊断"缺行为"和"缺区分度"两种失效原因，再分别对症处理，思路清晰。方法不改原始目标，可以直接叠加在现有的 GRPO 流程上。对做医疗、科研问答这类开放任务对齐的团队，有直接参考价值。

## 一句话概括

在不改动预训练扩散/流匹配机器人策略的前提下，同时在"输入噪声"和"输出动作"两个空间学残差，用在线 RL 更高效地提升策略。

## 核心方法

- **问题**：噪声空间残差方法（如 DSRL、LPS、LP-DS）用固定的几何区域（截断、投影到高斯球面、信赖域）限制噪声修改。但噪声改多少和解码出的动作好不好并不直接相关，这类硬约束可能挡掉"改动大但有用"的修改，所以样本效率明显落后于动作空间残差方法 DICE。
- **CNDO**：以高斯采样的噪声为锚点，学一个依赖状态和噪声的"修改方向"。它不再设硬性边界，改用"软保守约束"：一是用多个 critic 取最小值，压住价值高估；二是加门控执行，只有目标 critic 认为修改后更好时才采用这次编辑。
- **CANDO**：在 CNDO 之上再加一个动作空间残差。噪声分支负责结构性的行为改进，动作分支负责局部微调，两者联合训练。

## 关键结果

- CNDO 显著缩小了噪声空间方法与 DICE 之间的样本效率差距。
- CANDO 达到 76.1 NAUC、91.4% 最终成功率，比最好的单空间方法分别高 6.6 NAUC 和 4.1 个百分点。
- 把 DSRL 和 DICE 简单拼在一起几乎没有收益。只有两个分支各自能力相当时，联合训练才有明显增益。

## 为什么值得关注

对"冻结大模型策略 + 轻量在线适配"这一常见做法，论文给出两条实用结论：限制噪声修改时，应该看解码后的行为价值，而不是看噪声在隐空间里偏离了多远；多空间残差要真正互补，前提是各个分支单独都足够强。这对 VLA/扩散策略的真机 RL 微调有直接参考价值。

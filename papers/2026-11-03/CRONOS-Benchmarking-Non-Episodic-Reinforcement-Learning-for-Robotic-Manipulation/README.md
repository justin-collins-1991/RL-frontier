## 一句话概括

真实机器人做 RL 时很难每回合都靠人工重置场景。CRONOS 是一个仿真基准，专门研究预训练 VLA 在"很少重置场景"的条件下做 RL 微调会怎样。

## 核心方法

- 基于 ManiSkill3 / SimplerEnv 搭建 4 个场景，共 16 个"把物体放到容器上"的任务。同一场景里的多个任务共用桌面，上一个任务留下的摆放就是下一个任务的起点，误差会一路累积到后面的任务。
- 对比三种重置间隔：每个任务都重置（80 步）、每 4 个任务重置一次（320 步）、每 32 个任务重置一次（2560 步）。
- 用 PPO 微调 OpenVLA 和 SpatialVLA，评测时分单任务和连续多任务两种方式，并区分训练中见过和没见过的物体位置。

## 关键结果

- 直接微调效果很差：重置间隔从 80 步拉长到 320 步和 2560 步，OpenVLA 成功率从 65% 降到 37% 和 0%，SpatialVLA 从 65% 降到 25% 和 2%。
- 主要原因有两个：物体的初始摆放越来越分散；末端执行器的起始位姿偏离了预训练时的分布。
- 有针对性的处理能缓解问题：每次切换任务时把末端执行器复位（EER），可以修正预训练模型的偏差；训练早期多重置、后期再拉长间隔，可以提高交互效率。
- 非回合式训练的策略在没见过的物体位置和任务序列上泛化更好，长程操作也更强。

## 为什么值得关注

要把 RL 用在真实机器人上，人工重置场景的成本是主要瓶颈。这项工作首次在大规模 VLA 微调的设定下，把"少重置"这个问题拆解清楚了：失败的原因在哪，哪些重置策略真正有用。它还提供了一个可复现的基准。另一个发现是，少重置反而能带来更好的泛化，这对设计真实世界的 RL 流程有直接参考价值。

## 一句话概括

SPFT 让一份“看过标准答案”的冻结初始模型给 SFT 的每个目标 token 打权重。它不需要外部教师，也不需要在线采样，就能提升推理类任务的微调效果。

## 核心方法

作者先分析了现有的 token 加权 SFT。DFT 这类动态加权方法用训练中的模型给自己打分，导致目标分布越训越尖，极限情况下会塌缩到单一 token。静态加权方法用冻结的参考模型打分，训练目标固定为“数据分布 × 先验”，因此更稳定，但效果完全取决于先验的好坏。

SPFT 把初始模型复制一份并冻结，在输入中额外提供特权信息（如数学题的标准答案），再用它对目标 token 给出的概率作为静态权重。贝叶斯分解表明，这相当于在普通先验的基础上，按“该 token 对预测正确答案有多大帮助”再做一次加权，因此关键推理步骤会得到更高的权重。

## 关键结果

- 在数学推理和代码生成任务的主要设置中，SPFT 优于标准 SFT，也优于 DFT、PriFT 等加权基线。
- 消融实验表明，“固定不变的特权先验”是效果提升的关键。
- 分布可视化显示，DFT 很快把几乎全部概率压到 top-1 上。SPFT 只会选择性地放大先验支持的 token，其他候选仍保留一定概率。

## 为什么值得关注

这篇论文给 token 加权 SFT 提供了一个清晰的理论视角：动态加权会让分布不断变尖直至塌缩，静态加权的效果则取决于先验质量。方法本身完全离线，不依赖外部教师，计算成本接近普通 SFT，可以直接作为后续 RL 训练的更强起点。

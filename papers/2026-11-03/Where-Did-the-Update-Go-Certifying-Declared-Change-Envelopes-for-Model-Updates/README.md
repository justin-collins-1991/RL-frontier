## 一句话概括

有用的更新本来就要改变决策，所以关键是“改在了哪里”而非“改了多少”。论文用无标签流量认证更新是否越出声明范围。

## 核心方法

训练前先公布输入范围；更新后影子运行，范围外凡与旧模型决策不同都算“泄漏”。比较两个模型不需要标签，还能边监控边检验。降低泄漏靠“决策锚定”：在部署格式的无标签提示上蒸馏旧模型的决策。

## 关键结果

- 窄更新泄漏很广：领域和策略类 LoRA 改变的决策，仅约 7–36% 落在声明范围内。
- 256 个变体中，泄漏与范围外 KL 散度高度相关（Spearman 0.94）。
- 常规手段要么压不下泄漏，要么牺牲大量预期改动。
- 锚定后，LoRA、GRPO 和小学习率全量微调用几百到几千条无标签样本即可认证 5% 泄漏。
- 证书只覆盖类决策输出；开放式聊天中仅重新分批就有 11–21% 的回答实质变化，没有更新能通过。

## 为什么值得关注

欧盟和 FDA 已接受预先声明的变更，但缺少证据手段。RL 更新同样可能波及范围外决策，上线前还应审计范围外的决策翻转。

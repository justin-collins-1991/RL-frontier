## 一句话概括

用目标条件强化学习训练一个闭环 IK 策略，不依赖数值求解器，就能让机械臂末端在 1 mm / 0.2° 精度内到达并保持目标位姿。

## 核心方法

- **累积关节参考**：策略每步输出关节参考的增量，并观测"参考值 − 实测关节"的差。这样它能学会保留位置控制器静止时需要的那点偏置，抵消重力、有限增益造成的稳态误差。
- **两尺度误差 + 自适应步长**：位姿误差同时以厘米级和亚毫米级两种尺度输入，离目标越近动作增益越小，大范围移动和毫米级微调由同一个策略完成。
- **进步 + 驻留奖励**：只在刷新历史最优误差时给进步奖励，并对每个处于容差内的时间步计分，让策略既学会"到"也学会"稳"。
- **训练**：仿真中用 PPO 并行训练；真机上用 off-policy 的 FlashSAC，配合事后目标重标注、从近目标起点开始的逆向课程，节省机器人时间。

## 关键结果

- 仿真 7 自由度臂：单次尝试 93.5% 的测试任务满足 1 mm / 0.2°，中位误差 0.25 mm / 0.04°；加部署协议后成功率升至 98.9%。去掉任一设计，成功率下降 1.8–9.2 个点。
- 真机直接训练（OpenArm、xArm7）：在相同时间预算下，到达和保持成功率均高于 DLS、QP、MPC 等四种经典 IK 控制器（末段 5 s 持续保持：71.7% vs 最高 28.3%）。
- 给 π0.5 VLA 当执行层做仿真抓放，成功率 95.7%；CPU 单次推理仅 0.035 ms。

## 为什么值得关注

VLA 和跨本体迁移普遍输出末端位姿，最后执行精度取决于 IK。以往 RL 方法只能做到厘米级，或者最后一步仍要靠数值求解器修正。PolicyIK 证明纯 RL 策略也能做到毫米级到位和保持，并且可以直接在真机上训练，省掉了按机器人逐台调参的工作。它总结的三个设计（参考偏置可观测、多尺度误差、"到达 + 保持"奖励）也可以直接用到其他高精度控制任务上。

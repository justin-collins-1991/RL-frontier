## 一句话概括

不用强化学习去训练策略，而是用一个扩散模型根据任务条件直接“画”出策略网络的权重，一个模型就能覆盖多个环境的多种任务。

## 核心方法

提出 DPPG，由两部分组成，全部基于 Transformer：

- **参数自编码器**：把策略网络的参数切成小块（patchify），像处理图像 token 一样送进 Transformer，压缩成低维隐变量，压缩率高，因此能处理比以往工作更大的网络。
- **任务条件扩散模型**：在隐空间里做扩散，以环境/任务作为条件，从噪声生成对应的隐变量，再解码回完整的策略参数。

训练数据是各任务中用 RL 训好的策略 checkpoint。生成的参数可以直接用，也可以作为新任务的初始化。

## 关键结果

- 同一个 DPPG 模型能覆盖 Classic Control（5 个）、Atari（最多 20 个）、MuJoCo（5 个）等不同领域的任务，生成的策略表现与各任务从头训练的策略相当，部分任务还略好。
- 能生成的网络参数量比之前的参数生成方法更大。
- 在训练时没见过的环境里，用生成的参数做初始化，收敛更快，最终性能也有竞争力。

## 为什么值得关注

以往的参数生成工作基本只做图像分类这类监督任务；RL 策略的参数分布更分散，各任务的观测和动作空间也不一样，生成难度更大。这篇论文证明了“权重即生成对象”这条路在决策任务上也走得通。它给多任务 RL 和快速适配提供了一条新思路：直接按任务条件拿到一组好的初始权重，从而省掉一部分从零训练的成本。不过泛化目前只体现在“更好的初始化”上，离零样本直接可用还有距离。

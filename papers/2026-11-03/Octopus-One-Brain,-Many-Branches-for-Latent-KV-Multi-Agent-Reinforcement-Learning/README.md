## 一句话概括

把多智能体协作从“互发文本摘要”改成“在 GPU 上共享 KV 缓存”：同一个模型分出多个分支线程，用强化学习端到端训练它们分工合作做深度搜索。

## 核心方法

- **零拷贝分叉**：每个分支只是指向共享 KV 页的游标，开新分支几乎不花内存和时间，每个分支有独立的 32K 上下文预算；走进死胡同可以直接回退。
- **只挂到注意力层**：读取兄弟分支的结果时，直接把对方的 KV 挂进全注意力层，混合架构里的线性循环层（GDN/Mamba）则跳过这段，避免模型的“工作记忆”被带偏。跑题率从 57.9% 降到 2.7%。
- **打包 DAG-GRPO 训练**：把一个 episode 的所有分支打包成一次稀疏注意力前向，共享前缀只算一次；跨分支的 KV 挂载边保持可求导，并用“去掉某个分支后的奖励差”给每个分支分配功劳。

## 关键结果

- Qwen3.5-4B + BM25 检索：BrowseComp-Plus 达 49.6%，比 143K 长上下文单智能体 GRPO 高 17.5 个点，比文本摘要式多智能体 RL 高 12.5 个点；OpenResearcher 达 51.2%。
- 超过参数量大至 250 倍的稠密检索智能体；训练吞吐提升 3.3 倍，KV 显存峰值降低 2.8 倍。
- 只用结果奖励，模型自己学会了“指挥官-工人”式分工；测试时关掉分叉，准确率掉 21.7 个点。

## 为什么值得关注

它把多智能体协作下沉到推理引擎和显存管理这一层，证明“隐空间通信”可以做到在线策略、端到端训练，还能兼容混合循环架构。对长程检索类智能体来说，这是一条比硬拉长上下文窗口更省资源、效果也更好的扩展思路。

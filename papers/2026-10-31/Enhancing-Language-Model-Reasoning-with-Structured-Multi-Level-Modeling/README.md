## 一句话概括

把长思维链拆成“高层规划、低层执行”交替进行的两层过程，再配合分步偏好训练，让小模型在长推理中不容易跑偏。

## 核心方法

- **两层推理（MLR）**：高层规划器先写一句步骤描述，说明这一步用什么推理方式、要达成什么目标；低层执行器再展开细节。两者交替循环，计划可以随执行进展调整。
- **轻量实现**：底座模型做执行器，规划器只是一个 LoRA 模块。
- **迭代 Step-DPO**：结果奖励要等几千 token 跑完才拿到，难以定位出错步骤。作者用 Twisted SMC 估计每一步“走向正确答案”的可能性，据此构造逐步偏好对，无需额外训练过程奖励模型。

## 关键结果

- 在数学、科学、逻辑推理基准上，只用 R1 蒸馏方案 10% 的 SFT 数据和 5% 的偏好数据，MLR 就在多个底座模型上超过 SFT 蒸馏和 GRPO 等基线。
- 把多道题串起来模拟超长推理时，MLR 掉点更慢。

## 为什么值得关注

它以很低的成本把分层强化学习用到了 LLM 推理上，还为长轨迹的信用分配提供了免 PRM 的过程监督方案，适合资源有限、想提升小模型长链推理的团队。

## 一句话概括

只用普通离线语音翻译数据，靠两阶段 GRPO 强化学习，让离线 LLM 语音翻译模型"自己学会"多轮对话式同声传译，不需要合成读写轨迹，也不需要显式优化延迟。

## 核心方法

- **基座**：语音编码器 + 适配器 + LLM，先做 SFT 获得离线翻译能力（编码器冻结，LLM 用 LoRA）。
- **RL 阶段一**：在完整语音上用 GRPO 训练，以 COMET 作为奖励，先把离线翻译质量拉高。
- **RL 阶段二**：把语音切成块，按多轮对话逐块输入，模型每轮输出增量译文。对模型自己采样出的整条多轮轨迹打分，奖励包括翻译质量、单调性（译文顺序贴合源语音），并惩罚重复。核心思路是：离线模型面对部分输入时偶尔会表现出适合同传的行为，RL 把这些行为强化下来，模型就学会了每轮"该译什么、怎么译"。
- **推理**：不需要外部读写策略，逐块生成即可；调节输入块大小就能在质量和延迟之间切换。

## 关键结果

在 ACL 60/60 和 MCIF 两个基准、英→德/中/日三个方向上，SimPOTrans 的质量-延迟权衡优于多个强基线；同时它不仅翻译质量更高，输出行为也更适合同传场景。

## 为什么值得关注

现有对话式同传要么依赖对齐工具或 LLM 合成的读写轨迹（有噪声），要么联合优化质量和延迟（目标冲突、训练不稳定、容易 reward hacking）。SimPOTrans 把问题简化为"用 RL 让模型在部分输入上自我适应"，数据门槛低，一个模型覆盖多种延迟档位，部署简单。对于把 RL 后训练用到流式、增量生成任务上，这是一个很好参考的范式。

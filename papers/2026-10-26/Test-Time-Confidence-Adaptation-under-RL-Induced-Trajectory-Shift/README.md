## 一句话概括

Agentic RL 会改变模型的推理轨迹，导致在 Base 模型上训练好的置信度估计器失效。作者发现“轨迹越稳定，答案越可能正确”这条规律在 RL 前后基本不变，于是拿它当无标签信号，在测试时把置信度估计器适配到 RL 模型上。

## 核心方法

StaR-TTA 分两阶段：
- **源端训练（有标签）**：在 Base 模型轨迹上，同时用正确性标签和“稳定性→可靠性”的排序信号训练置信度打分器，再接一个校准器把分数映射成概率。稳定性的测法是：固定答题前的轨迹前缀，多次只采样短答案，看答案的一致程度。
- **测试时适配（无标签）**：对 RL 模型的新轨迹计算稳定性，构造“谁更可靠”的成对排序，用排序损失微调一个修正模块；原打分器和校准器保持冻结，这样分数尺度不会被破坏。

## 关键结果

- RL 之后，MICE、CCPS 等依赖轨迹的估计器 AUROC 相对下降 23%~34%。对照实验显示，把 RL 轨迹换回 Base 轨迹可以挽回相当一部分损失，说明主因是轨迹分布偏移。
- 稳定性信号本身在 RL 前后预测正确性的 AUROC 都在 0.7~0.8 左右。
- StaR-TTA 在四个 QA 基准上平均 AUROC 达到 0.721，在未见数据集、不同模型家族与规模、不同 RL 算法上都有一致提升。

## 为什么值得关注

模型每做一轮 RL，就要重新标注数据、重训置信度估计器，成本很高。这篇工作给出了一个低成本方案：不需要目标标签，靠模型自身输出的一致性就能完成迁移。对部署 Search-R1 这类 RL 训练的智能体、并需要可靠拒答或风险控制的场景，实用价值较高。

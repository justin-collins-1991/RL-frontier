## 一句话概括

多目标 RL 难不难学，取决于目标之间冲突有多大。论文先给这种冲突定了一个量化指标，再提出两种缓解办法：一是维护少量“基策略”，把轨迹分给最合适的那个去学；二是给轨迹做归因，挑出有益的轨迹来训练。

## 核心方法

- **目标冲突系数**：用来衡量不同偏好权重下最优策略差多远。论文把它和探索难度（可覆盖性）放在一起，推出在线 regret 上界，并证明这个上界接近最优。结论很直观：目标越冲突，跨偏好复用数据越难。
- **路由集成策略学习**：不再为每个偏好单独训一个策略，只维护一小组基策略。每条轨迹按当前偏好路由给预期回报最高的基策略，各基策略再用分到的轨迹跑 PPO 等标准算法更新。
- **核代理轨迹归因**：用核岭回归拟合“选哪些轨迹训练、策略最终表现如何”之间的关系。它能捕捉轨迹之间互相促进或互相拖累的非线性作用，再借助策略梯度和随机投影降低计算成本，结果可用来筛选轨迹。

## 关键结果

- Meta-World 上，路由集成比最强基线高 4.3%；MO-Gymnasium 上超体积平均提升 8%，RLHF 场景结论类似。
- 路由后可覆盖性指标从单策略的 1.3 降到 0.2，说明目标冲突带来的探索瓶颈确实变小了。
- 核归因与留一法真值的 Spearman 相关性比现有方法高 50%；用它筛选轨迹，回报比基线归因方法高 27%。

## 为什么值得关注

RLHF 里有用性、安全性、诚实性要权衡，机器人里有速度和能耗要权衡，多目标问题到处都有。这篇论文先从理论上讲清“冲突越大越难学”，再给出两个容易落地的工具：少量基策略加路由，比按偏好逐个训练更省样本；轨迹归因可以用来识别被污染的奖励，或者给数据做筛选。做对齐和后训练的数据工程时可以参考。

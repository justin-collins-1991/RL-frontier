## 一句话概括

BCMAAC 在多智能体 Actor-Critic 中引入可学习的"信念"表示，帮助去中心化执行的 LLM 智能体推断环境隐藏状态和队友意图，从而提升协作效果。

## 核心方法

- **信念编码器**：每个智能体用一个循环编码器，把执行时可获得的结构化侧信息（含收到的消息）压缩成跨轮次的信念上下文，作为 LLM actor 的额外输入。不再只靠 actor 从冗长的文本历史中自行重建任务状态。
- **辅助监督**：编码器有两个只在训练时使用的预测头，分别预测任务隐藏状态和队友动作。监督标签由环境内部状态等特权信息事后生成，执行时不用。
- **集中式 Critic**：训练时把所有智能体的信念上下文拼起来估计团队价值，执行时各智能体只依赖自己的历史和信念，保持去中心化。论文还证明，以信念作为 baseline 不会让策略梯度产生偏差。

## 关键结果

在 Minecraft 游戏、网页搜索和工具调用三类协作任务上，BCMAAC 的任务表现和协作行为都优于朴素 MAAC 基线。多轮、上下文信息丰富的任务提升最明显。消融实验表明，任务信念和队友动作两个辅助信号都有贡献。

## 为什么值得关注

多 LLM 协作走向 RL 训练后，最大难点是部分可观测和长程稀疏奖励。本文提供了一个轻量方案：用紧凑的中间表示替代原始长文本历史来做价值估计和决策，并借助训练期特权信息进行监督。这套方法容易迁移到其他 CTDE 式的 LLM 多智能体训练框架中。

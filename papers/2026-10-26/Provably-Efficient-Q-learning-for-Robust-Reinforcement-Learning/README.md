## 一句话概括

提出一种只需单条马尔可夫轨迹、O(SA) 内存的无模型鲁棒 Q-learning，样本复杂度接近极小极大最优，明显优于已有方法。

## 核心方法

鲁棒 RL 要优化的是“环境在一定范围内变坏时”的最差表现（论文用 TV 距离、半径 σ 刻画环境不确定性）。难点在于：数据来自标称环境，而更新需要的是最坏环境下的下一状态。作者发现，TV 不确定集下的最坏转移可以用一个简单操作实现：对观测到的下一状态按价值做阈值截断，价值过高的样本被“重定向”到一个固定状态。据此用真实样本构造一个“替身下一状态”，直接套用普通 Q-learning 的更新形式。为避免估计值与采样构造互相干扰，构造替身状态时使用较早阶段的价值函数。整个过程不估计转移矩阵，也不需要模拟器。

## 关键结果

- 异步（单轨迹）设定下，样本复杂度主项约为 1/(μ_min·ε²·(1-γ)³·max{1-γ, σ})，只比极小极大下界多一个 1/(1-γ) 因子，而这个因子对 Q-learning 类算法本身就难以避免；
- 相比此前单轨迹方法（Yang et al., 2023）有数量级提升，收敛速度从 t^(-1/3) 提升到标准的 t^(-1/2) 水平；
- 不超过标准 Q-learning 的样本复杂度，σ 较大时反而还要更少；
- 可直接推广到生成模型（同步）设定，结果同样接近最优。

## 为什么值得关注

现实中多数数据是沿着一条轨迹采集的，而先前的鲁棒 RL 方法要么需要 O(S²A) 内存存模型，要么依赖能任意查询的模拟器，要么收敛很慢。这项工作首次在“无模型 + 单轨迹 + 最优内存”这三项条件下给出接近最优的理论保证，“重采样构造最坏状态”这个思路简单易实现，可以作为 sim-to-real 场景下鲁棒值学习算法的理论基础。

## 一句话概括

EvoRouter 让路由器为每个查询一次性规划整套多智能体配置，包括用哪个模型、什么协作模式、几个 agent、交互几轮、配哪些技能。它把执行中积累的"洞见"通过在线策略蒸馏（OPD）学进策略，从而做到准确率更高、算力更省。

## 核心方法

- **洞见提炼**：由一个专家 LLM 定期汇总跨任务的配置轨迹和"效果-成本"反馈，总结成带适用条件的路由规律。比如不同任务该扩哪类资源、轮数和 agent 数加多了收益反而下降、模型组合和协作模式之间如何搭配。
- **特权教师 + OPD**：教师模型能看到这些洞见和当前的执行反馈，对路由器自己生成的规划逐 token 打分，把稀疏的终局奖励变成密集监督。推理时不需要这些特权信息。
- **成本感知 RL**：在 SFT 冷启动之后，用组相对 RL 同时优化任务成功率和计算开销。
- **自我改进闭环**：更新后的策略产生新轨迹，再用来提炼新洞见，如此循环。

## 关键结果

在 5 个领域的 19 个域内数据集和 2 个域外基准上评测。域内平均准确率 68.69%，比最强的路由基线高 7.23 个百分点，推理算力成本降低 50.95%，鲁棒性也更好。代码已开源。

## 为什么值得关注

多智能体服务的配置空间会组合爆炸，而终局奖励太稀疏，难以说清是哪一步决策出了问题。这篇论文给出了一套可复用的思路：先把经验总结成"带条件的规则"，再借在线策略蒸馏把它们变成逐 token 的监督。这把"显式经验积累"和"参数化策略学习"连了起来，对想用 RL 做 agent 编排、在成本和效果之间权衡的工程团队有直接参考价值。

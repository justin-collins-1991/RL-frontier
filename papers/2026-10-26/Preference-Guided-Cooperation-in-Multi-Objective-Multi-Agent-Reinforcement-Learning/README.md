## 一句话概括

在多目标多智能体强化学习（MOMARL）中，不把"多目标"当成额外负担，而是让每个智能体学会自己的目标偏好，用多目标结构反过来促进团队协作。

## 核心方法

- 双层偏好：团队层面有一个固定的团队偏好，定义系统想要的目标权衡；每个智能体另有一个可学习的个体偏好，决定"我这一步更该关注哪个目标"。
- 按目标的反事实信用分配：沿用 COMA 的反事实基线思路，但对每个团队目标分别评估单个智能体的贡献，得到分目标的学习信号，缓解"躺赢"的 lazy agent 问题。
- 元梯度调偏好：个体偏好影响策略怎么更新，所以学偏好本身是个 learning-to-learn 问题。作者把个体偏好当作元变量，根据"这次策略更新对后续团队表现的影响"来更新它。
- 两个变体：MIRL-S 学一组静态偏好；MIRL-D 根据当前协作情境动态调整偏好。

## 关键结果

在多目标版的 Multi-Agent Particle Environment 上，MIRL 的 Pareto 前沿质量稳定优于各类基线，动态变体 MIRL-D 整体表现最好。实验目前只覆盖粒子环境这类较简单的场景。

## 为什么值得关注

以往 MOMARL 方法大多把"协作"和"多目标权衡"拆开处理，复杂度很高。这篇工作给出了另一个角度：让智能体自己分工去关注不同目标，本身就是一种协作机制。对自动驾驶车队、无人机编队这类既要多体配合、又要兼顾多个指标的系统，"个体偏好 + 元梯度对齐团队目标"是一个值得借鉴的设计。

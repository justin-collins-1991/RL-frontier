## 一句话概括

VeriCUA 把“电脑操作智能体（CUA）是否真正完成任务”的判定，从被动看截图变成主动探索取证，一套流程通用于多平台及在线、离线场景。

## 核心方法

验证器先查看应用和现有记录，再结合指令拆出细粒度检查清单，避免凭空假设文件位置或界面元素。随后针对未确认的要求，自主选择 GUI 或代码手段取证：离线翻录制帧和动作日志，在线读文件、数据库等机器状态。最后按显式证据规则裁决。智能体自称“已完成”不算证据，证据不足时可以弃权。

## 关键结果

- 在各评测场景下，与参考标签的一致率均高于对比基线，离线提升主要在难例上。
- 在线场景比 VLM 评判更能识破虚假的完成声明。
- 加入代码读状态后，可判定样本增多，假阳性没有增加；验证轮数相同时，补充视觉证据优于重复同一配置。

## 为什么值得关注

“是否完成”的判定是 CUA 评测、数据筛选和强化学习反馈的基础，而现有方法只能看到局部信息，为各平台定制验证器的成本又高。VeriCUA 提供了统一的验证框架，也适用于没有专用检查器的应用。

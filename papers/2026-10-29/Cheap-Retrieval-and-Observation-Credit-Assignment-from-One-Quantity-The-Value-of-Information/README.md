## 一句话概括

把"该检索哪段记忆"和"该奖励哪次观察"这两个记忆型 RL 难题，归结为同一个量：信息价值（这条信息让可达回报提高了多少）。

## 核心方法

- 在历史轨迹上训练世界模型，把某段历史遮住后再在模型里重新优化，用"有它"和"没它"的回报差来估计信息价值，不需要额外采集轨迹。
- 在观测处读取：给"去看一眼"这类动作的 TD 目标加一个可证明的下界，让信用直接跳回当初获取信息的那一步，不必靠 Bellman 逐步回传。
- 在决策处读取：信息价值减去检索成本，就是最优检索集合。
- 配套原型 Memory Navigation：用一个指针在按时空索引的外部记忆里按相对步长移动，检索代价与记忆库大小无关。

## 关键结果

- 理论上证明信息价值给出最优动作价值的下界。
- 原型在 MiniGrid-Memory 上只用 5 个 token 的上下文，约 0.59M 步达到 0.95 回报，快于绝对位置检索（0.94M）和无检索头的基线（1.38M）。
- 注意：信息价值估计器和下界 TD 目标都还没实现，原型也还没用上这个信号，收敛更快目前只是假设。

## 为什么值得关注

机器人在延迟和能耗上受限，长时程记忆任务又常卡在"先行动才能观察"的信用分配上。本文用一个量把这两个问题串起来，思路清晰，但目前仍是 workshop 阶段的框架性工作，实证还有待补足。

## 一句话概括

在 DreamerV3 这类潜空间世界模型里，不再用固定的想象步长，而是按每条想象轨迹的"可信程度"动态决定什么时候停止展开模型回报，转而用 critic 自举（bootstrap）。

## 核心方法

- **密度代理信号**：用回放数据的潜特征训练一个特征位移网络和一个带噪声条件的 score 估计器，两者组合成一个修正后的辅助向量场；沿想象轨迹累加这个场的负散度，得到一个"相对密度"指标，用来判断轨迹是否走进了模型不熟悉的区域。
- **两种门控**：硬边界在某一步直接截断回报展开；软边界则逐步把回报递推的权重从模型预测移向 critic 估值。两种方式都保留边界处的价值估计，并给 actor/critic 损失乘上对应的"存活权重"。
- **理论保证**：证明门控后的 Bellman 算子仍是严格压缩映射，且越早自举，目标方差单调下降。作者也明确说明，这个代理不是精确的路径似然。

## 关键结果

在多个连续控制任务和 Atari Pong 上，与固定步长的 DreamerV3、以及只加辅助模块但不做边界选择的基线相比，动态边界的样本效率更高，训练后期表现也更好。实验还加入了固定边界对照、score 消融和阈值敏感性分析，用来区分"密度信号确实有用"和"只是步长变短了"这两种解释。

## 为什么值得关注

"想象多少步才合适"是基于模型的强化学习的老问题。本文给出一种不依赖集成、可以直接接入现有世界模型的逐轨迹门控方案，而且对自身局限说得很坦白：目前仍会生成完整的想象轨迹，所以不能节省 rollout 计算；密度代理是否真能反映模型误差，作者也把它当作待实验验证的假设，而非已有定论。

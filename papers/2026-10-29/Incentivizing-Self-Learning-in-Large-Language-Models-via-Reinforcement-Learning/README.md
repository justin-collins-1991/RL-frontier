## 一句话概括

让模型像人一样，遇到陌生的题目时自己翻教材、看懂相关定理，再用来写证明。作者用强化学习训练这种"现学现用"的能力，训练出来的策略还能迁移到其他长上下文任务上。

## 核心方法

- **任务构造**：把 158 本高等数学教材解析成按章节索引的文本，抽出 5,183 道证明题。参考答案对模型隐藏，模型只能看正文里的定义、定理和例证。
- **BookNavigator 工具**：只提供三个动作：看目录、按关键词搜索、读整节内容。推理和查书交替进行，最后输出完整证明，由 LLM 裁判对照隐藏的答案判断对错。
- **细粒度奖励（基于 GRPO）**：
  - 退火探索奖励：证明正确且查过书时给额外加分，防止模型学会"不查书硬做"。
  - 轮次级工具打分：用冻结的初始模型给每次查书标注有用、中性或有害，再按这个标注重新分配每一轮的 advantage，少强化无效的查询。

## 关键结果

- Intern-S2-Preview-35B 的整体证明准确率从 51.5% 提升到 79.5%。在训练过的教材、没见过的教材和没见过的学科上都是最好的，比最强的固定检索 RL 基线高 6.4 个百分点。
- 不用 BookNavigator 时，在 BrowseComp-Plus 和 CL-bench 上也分别提升 1.7 和 2.3 个百分点。
- 消融实验：只奖励答案正确会压制查书行为。探索奖励和工具打分一起用，跨域效果最好，而且不需要把调用次数堆到最多。

## 为什么值得关注

这项工作把重点从"让模型多记知识"转到"让模型学会怎么学"。教材这类长文本语料量大、容易获取，可以拿来做 RL 环境。文中的"探索奖励 + 按轮次给工具调用打分"也是一种实用的做法，能缓解多轮工具调用 agent 中常见的两个问题：工具没人用，以及无效调用被一起奖励。

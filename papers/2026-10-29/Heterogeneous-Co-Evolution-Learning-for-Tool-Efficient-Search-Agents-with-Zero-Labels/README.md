## 一句话概括

ZEST-Search 不用任何标注数据，让一个"出题者"按解题者当前水平在线出题，"解题者"用强化学习练搜索推理，同时奖励"答对且少搜"。

## 核心方法

- **零标注出题**：从无标签的参考问题出发，先定答案、再沿证据路径反推问题，并做校验，保证题目可解、答案可靠。
- **异构协同进化**：出题者和解题者是不同的模型，出题者围绕解题者的能力边界动态调整题目，题库跟着解题者一起变强，不再是固定数据集。
- **两套奖励**：出题者拿"中等难度奖励"，题目太易或太难都不给分，鼓励出最有信息量的题；解题者拿"工具感知奖励"，在同一道题的多条轨迹之间比较，答对且搜索次数更少的拿更高分，抑制冗余检索。

## 关键结果

在 7 个通用问答和多跳问答基准上，ZEST-Search 稳定提升搜索智能体的准确率，同时工具调用效率更高，全程不需要带标注的搜索训练数据或专家轨迹。消融分析表明，异构出题、自适应难度控制和工具感知优化三者都有贡献。（基于摘要）

## 为什么值得关注

搜索智能体训练有两个老问题：高质量多跳训练数据难造，纯结果奖励又会让模型"多搜几次碰运气"。本文用自博弈式课程解决数据问题，用组内相对的工具奖励解决效率问题，两者都可以低成本迁移到其他工具调用型 Agent 的 RL 训练里，对关心推理成本和延迟的落地场景尤其实用。

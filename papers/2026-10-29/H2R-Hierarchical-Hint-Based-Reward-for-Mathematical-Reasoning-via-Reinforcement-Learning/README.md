## 一句话概括

把数学题自带的子问题结构拆成分层提示，作为 RLVR 训练中的中间条件信号，给长链推理补上“中途检查点”。

## 核心方法

- **问题**：RLVR 通常只看最终答案对不对，多步推理缺少中间监督，信号稀疏。
- **分层提示（Hierarchical Hints）**：利用题目内在的子问题结构，逐层给出逻辑上可靠的中间里程碑。和 CoT 提示不同，它不教模型怎么想，而是直接缩短从当前状态到最终答案的推理距离。
- **H$^2$R**：把这些分层提示接入 RL 训练和奖励设计，让模型在训练中拿到更密集的结构化信号。
- **HiMath**：作者构建的分层结构数学题基准，用于验证该框架。

## 关键结果

- 不做专门训练、只加分层提示，多个不同 LLM 的推理表现都稳定提升。
- 用 H$^2$R 训练后，Qwen2.5-Math-7B 在 HiMath 上的准确率从 30.4% 升到 39.1%；如果用 Oracle 分层提示，最高到 45.6%。

（基于摘要）

## 为什么值得关注

RLVR 对复杂多步任务的中间监督有限，H$^2$R 的思路是直接复用题目的子问题结构当检查点。Oracle 提示比普通提示还高 6.5 个百分点，说明提示质量可能仍有提升空间。对做多步推理 RL 的团队，这提供了一个奖励设计方向。

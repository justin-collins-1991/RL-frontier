## 一句话概括

当路被可移动障碍物堵住时，让四足机器人用一个 LoRA 微调的小语言模型决定“推哪个、推到哪、再走去哪”，底层交给 RL 策略执行。

## 核心方法

- **高层规划器**：用 LoRA 在合成数据上微调 Qwen2.5-1.5B。输入是自然语言任务和结构化场景（机器人与物体位姿、尺寸），输出是一串不定长的参数化动作，每步同时给出技能（导航/推动）、目标物体和几何目标位姿。采用事件驱动方式：每次只执行第一步，执行完再重新规划。
- **底层技能**：一个导航策略，外加一个端到端全身平面推动策略。推动策略不依赖“速度指令 + 固定步态”的分层结构，可以自己学出更适合推物体的身体动作。

## 关键结果

- 规划器在交互式导航任务上优于经典规划器和直接提示的前沿大模型。
- 从零训练的模型对比显示：表示结构化时，技能组合不依赖预训练；但预训练能让几何目标更可靠。
- 推动策略仿真成功率 93.3%，分层基线为 83.5%，完成时间缩短 60% 以上。
- 真机 45 次试验中，技能组合正确 44 次，端到端成功 34 次。

## 为什么值得关注

它把“推哪个、推到哪”交给一个 1.5B 的小模型做，不需要长提示词，靠合成数据就能学到几何关系，部署成本低。同时实验说明，用端到端策略取代“锁定步态的运动控制器”对非抓取操作有明显收益，可以为腿足机器人做移动操作提供参考。不足是物体位姿依赖动捕系统，感知部分还没有解决。

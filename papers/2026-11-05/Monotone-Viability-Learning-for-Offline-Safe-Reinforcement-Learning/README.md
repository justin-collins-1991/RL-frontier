## 一句话概括

MoViL 不再拟合带折扣的安全价值函数，而是从离线数据中逐层学习"能安全撑过 k 步"的状态集合，最终逼近"永远安全"的可行区域，并在部署时用它审核策略动作。

## 核心方法

- **逐层收缩的可行集**：第 0 层是当下安全的状态；第 k 层只保留"存在某个动作能安全转移到第 k-1 层集合"的状态。层数越多，集合越小，理论上收敛到 HJ 可行核（能无限期保持安全的最大区域）。
- **二值监督**：每层训练一个分类器，标签就是"这条转移无违规且后继状态在上一层集合内"（0/1）。目标尺度不随时域变化，避开折扣价值在长时域上数值衰减、安全边界难以区分的问题。
- **离线可恢复性**：给出在行为数据覆盖下，能恢复"行为策略支撑的可行子集"的充分条件。
- **部署时动作认证**：一个简单的高斯行为克隆策略给出候选动作，动作级安全估计器负责审核；不通过时按代价估计从备选动作中挑一个。

## 关键结果

- Dubins 小车实验中，学到的可行集与独立的 HJ 数值参考解吻合良好。
- 在 DSRL 的 17 个 Bullet-Safety-Gym 和 MetaDrive 任务上取得 SOTA 的奖励-代价表现，**每个任务都满足平均代价约束**，平均代价在对比方法中最低。

## 为什么值得关注

现有可达性类安全 RL（如 FISOR）大多依赖折扣 Bellman 拟合标量值，阈值缺乏明确的安全含义，长时域下数值也不稳定。MoViL 用"集合递推 + 二分类"同时兼顾语义正确、收敛性和数值稳定，而且不需要动力学模型、不需要在线探索，实现上也很工程友好（分类器 + BC + 动作过滤）。对机器人、自动驾驶这类没有可靠模型、试错代价又高的场景，这是一条实用的离线安全落地思路。

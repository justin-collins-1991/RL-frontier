## 一句话概括

用 LLM 从自然语言任务描述自动生成奖励机（RM），再让 VLM 看图判断命题是否成立、充当标签函数。这样做依赖历史的非马尔可夫任务时，既不用手工设计奖励，也不用读环境内部状态。

## 核心方法

- **LLM 生成 RM**：先从任务描述里抽出一组共享的原子命题（如"拿到钥匙"），再把任务拆成子任务自动机，最后合成一个完整的 RM。整个过程只需调用几次 LLM。
- **VLM 当标签函数**：VLM 逐帧判断哪些命题成立。RM 负责记住"任务做到哪一步"，VLM 只需看懂单张图，不用从图像序列里推断进度，因此避开了 VLM 偏向给序列后面的帧打高分的问题。
- **抗噪的 RM 状态信念**：VLM 打标签会出错，所以不硬性认定当前处于哪个 RM 状态，而是维护一个状态概率分布（结合每个命题的真/假阳性率和命题之间的共现先验），奖励按期望累计 RM 奖励的变化来算。
- **稠密奖励**：用 GVL 零样本估计离下一次 RM 转移还有多远，作为塑形奖励加快学习。
- 离线可复用同一份 VLM 标注数据集训练多个任务；在线则把 VLM 标签蒸馏成一个轻量分类器来用。

## 关键结果

在非马尔可夫网格导航、机器人操作、部分可观测 3D 物体收集三个领域上，RM-VLM 的任务成功率都高于现有基于 VLM 的奖励方法。GVL 稠密奖励让学习更快，但不改变最终性能。

## 为什么值得关注

RM 落地的最大障碍是每个环境都要手工写标签函数。这篇工作用"LLM 管结构、VLM 管感知"的分工把这一步自动化了，并且显式处理了感知噪声，对基于图像的真实机器人长程任务很有参考价值。思路也清楚：时序记忆交给符号自动机，基础模型只负责单帧识别。

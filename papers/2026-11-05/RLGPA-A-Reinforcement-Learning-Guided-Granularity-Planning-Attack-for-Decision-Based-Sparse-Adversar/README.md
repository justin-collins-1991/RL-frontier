## 一句话概括

在只能拿到 top-1 标签的黑盒场景下，用在线强化学习按攻击进度动态决定“用哪种还原策略、以多大粒度还原像素”，从而用更少查询得到更稀疏的对抗样本。

## 核心方法

- **问题视角**：从一个已成功的对抗图出发，不断把被扰动的像素“还原”回原图，同时保证仍然攻击成功，目标是让被改动的像素尽量少。早期大块还原效率高，后期则需要细粒度、参考历史结果的试探，固定调度无法兼顾。
- **稳定的宏动作**：RL 智能体不直接挑选具体像素组（分组每轮都会变，Q 值没有意义），而是从 7 个“策略 × 相对粒度”组合中选择。三种还原策略分别按扰动大小升序、考虑幅值、利用历史成败记忆；粒度按当前剩余扰动量的比例设定，因此在不同分辨率的数据集上含义一致。
- **状态与学习**：状态只描述搜索进度，包括剩余扰动比例、阶段、连续停滞次数、上一步收益与接受率、剩余预算等。决策器是带动作掩码的 Dueling Double DQN，可以跨决策步、跨图像在线复用经验。
- **安全执行器**：每次只提交经标签验证仍然成功的还原，失败就回滚，保证扰动支撑集单调缩小、对抗性不丢失；每次决策后都按当前扰动重新分组。

## 关键结果

- CIFAR-10 定向攻击、稀疏度 0.01 时，成功率 61%，SparseEvo 为 25%，Pointwise 为 0%。
- ImageNet 稀疏度 0.005 时，在 ResNet50 和 ViT 上成功率分别为 75.5% 和 73.0%，基线仅为 29.0% 和 15.5%。
- 把策略冻结后测试：在线学过 40 张图后，中位 L0 从 165 降到 23。
- 消融显示，屏蔽状态或打乱状态后性能明显下降，说明收益确实来自“按状态调度 + 动态重分组”。

## 为什么值得关注

这是“RL 当调度器”的典型做法：不让 RL 直接操作像素，而是在一组语义稳定的算子之间按状态做选择。这种思路可以迁移到其他组合搜索问题。对防御方来说，它说明只暴露 top-1 标签的模型也可能被只改极少像素的攻击击穿，评估鲁棒性时需要把这类自适应稀疏攻击纳入考量。

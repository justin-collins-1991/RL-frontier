## 一句话概括

先让一个"看不见奖励"的预训练决策模型（DM）只读任务的文字描述就去做决策，再用 RL 从奖励里接着改进，解决稀疏奖励下从零探索太慢的问题。

## 核心方法

DMGT 分三步：
1. **文字化状态**：把每个状态写成自然语言 query，内容包括环境、目标、数值含义、当前状态、近期历史、当前最紧急的事、策略提示和可选动作。
2. **DM 选动作**：DM 的工作方式像分类器，一次前向就给每个选项打出概率，取最大的那个当动作。它不生成文本，所以不用解析输出，也比 LLM 当老师便宜得多。
3. **模仿 + 微调**：用 BC 或 DAgger 让策略网络模仿 DM 的决策，然后交给标准 PPO 只靠环境奖励继续优化，这一阶段不再调用 DM。

## 关键结果

- 在 6 个环境的 7 个任务上，DMGT 全部超过纯 PPO，收敛也更快；有 5 个任务超过 DM 本身。
- Lunar Lander：PPO 跑 1M 步都没解决；DMGT 只用 DM 的一次成功着陆做初始化，216k 步平均回报就到了 200，测试 20/20 成功，DM 本身是 18/20。
- 消融结论：DM 读不懂 PPO 用的原始观测；每个动作必须描述准确；关键是给对信息而不是给多信息（精简描述效果和完整版相当）；文本顺序、小数位数这类表面细节基本没影响。

## 为什么值得关注

过去给 RL 开局通常要先准备人类示范、训练好的老师或手写控制器。DMGT 只需要一段任务描述，冷启动成本低很多。论文还给出了一套可以直接照着用的"怎么给 DM 写描述"的指南，对用基础模型给 RL 做先验的工程实践有直接参考价值。

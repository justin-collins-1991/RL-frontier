## 一句话概括

同样用 LoRA，SFT 和 RL 训练出的低秩增量形态截然不同：RL 的奇异值更集中、子空间旋转更快。根源是 GRPO 里的组均值基线减法，据此可以为两个阶段分别定制 LoRA 优化器。

## 核心方法

- **诊断**：在数学推理任务上跟踪 LoRA 增量的有效秩（奇异值是否均匀分布）和左右奇异子空间的重叠度（方向是否在变）。
- **逐项插值定位原因**：从 SFT → 拒绝采样微调 RFT → RFT 加组均值基线 → GRPO，每次只改一个要素，发现差异只在加入基线后出现。
- **理论解释**：用二次多指标模型说明，“相干拟合”会把能量集中到少数方向，梯度噪声则会把能量摊开。基线减法削弱了组内共享的梯度分量，结果是谱更集中、方向更易漂移，同时最优学习率被压低。
- **按阶段定制**：SFT 用类 Muon 的方式把整个更新的谱压平，让适配分散到更多方向；RL 只压平落在当前 LoRA 子空间之外的那部分更新，以促进子空间旋转。

## 关键结果

- 在多个 Llama、Qwen 模型和 GSM8K、MATH 上，RL 在所有学习率下都让谱更集中；SFT 在中等学习率下让谱变宽。小学习率下 RL 子空间旋转明显快于 SFT。
- 两个阶段各自的定制配置在大多数评测设置下取得了对比方法中的最佳效果。

## 为什么值得关注

它把“RL 学习率要小”“RL 更新更稀疏”这类经验现象，落到了 LoRA 增量的谱和子空间这一可测量的层面，并给出机制解释。对实践的提示是：SFT 和 RL 不应沿用同一套 LoRA 优化配置，基于 Muon 的谱压平思路可以按阶段做针对性调整。

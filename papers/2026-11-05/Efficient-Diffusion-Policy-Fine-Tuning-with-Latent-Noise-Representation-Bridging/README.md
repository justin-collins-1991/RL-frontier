## 一句话概括

冻结预训练的扩散/流策略，只用 RL 学“喂给它什么初始噪声”，并通过一个噪声与动作共享的表征，消除“噪声混叠”问题，让微调又省算力又省样本。

## 核心方法

- **只调初始噪声**：DDIM、流模型在初始噪声确定后生成过程是确定的，因此可以把预训练模型当黑盒，只训练一个输出初始噪声的小网络，免去整条去噪链上的反向传播（BPTT）。
- **噪声混叠问题**：不同噪声可能生成相同动作，相近噪声又可能生成差异很大的动作，因此噪声空间的 Q 值与动作空间的 Q 值很难对齐，以往方法只能在噪声空间另外训练一套 critic。
- **LNL-MDP 与 Bridge Equation**：假设环境是线性 MDP，把动作特征经由预训练策略“拉回”到噪声空间，得到的噪声空间 MDP 同样是线性的。这样，状态-动作对和状态-噪声对共用同一套表征和同一个 Q 函数，两边的价值天然对齐，混叠问题随之消失。
- **理论保证**：把预训练模型视作一个“虚拟数据集”，整个框架可以纳入 FineTuneRL 理论，继承其近最优的样本复杂度界。
- **LARBRID 算法**：先从零学习共享表征，再在此表征上做 RL，优化初始噪声分布。

## 关键结果

在多种机器人运动与操作任务上与多个 SOTA 基线对比，困难控制任务上性能最高提升 2–3 倍，样本效率也更高。

## 为什么值得关注

扩散/流策略已经成为机器人基础模型的主流骨干。这篇论文提供了一种只需 API 访问、无需改动模型权重的 RL 微调方案，部署成本低。它还用一个共享表征同时解决了“噪声混叠”和“缺乏理论保证”两个问题，把线性 MDP 理论落到了大模型微调的实际场景中。

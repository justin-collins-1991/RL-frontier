## 一句话概括

先用 SAC 学会海上风电场的"隐式平衡"控制，再把黑盒策略蒸馏成透明的可解释提升机（EBM）。蒸馏时按价值加权，再结合专家知识筛选特征，得到一个能上线、能讲清楚理由的控制器。

## 核心方法

- **问题建模**：风场根据 TSO 发布的实时信息调整功率设定点，偏离交易计划以帮助系统平衡并降低不平衡成本。每个 15 分钟结算周期作为一个 episode，状态包括最新价格估计、系统不平衡预测、累计偏差、功率预测误差和周期内分钟数。模拟器按比利时 TSO 的实际公式计算价格，因此考虑了风场动作对价格的反作用。
- **教师策略**：用 SAC 训练出性能好但不透明的策略。
- **学生模型**：采用 EBM（带两两交互项的广义加性模型）。每个特征的作用都能画成曲线或热力图，单次决策等于各项之和。
- **价值导向蒸馏**：借鉴能源预测中的"价值导向"思路，按样本回报给蒸馏损失加权，让学生优先模仿收益高的关键动作，而不是平均地拟合所有动作。
- **专家参与建模**：先训练完整模型，再结合市场专家意见删除或补充单变量项和交互项，确保每个效应都能向 TSO 和运营方解释清楚。

## 关键结果

在比利时 2022–2023 年电网数据和 Norther 海上风电场的真实 SCADA 数据上测试，价值导向加专家设计的 EBM 控制器把不平衡成本降低了 82%，优于价格阈值控制器和基于决策树的蒸馏基线。

## 为什么值得关注

RL 在能源调度上表现不错，但因为是黑盒，一直难以真正部署。这篇工作给出了一条可落地的路线：先用 RL 求解，再做价值加权蒸馏，最后由专家审核。它同时兼顾了性能、透明和可辩护，这套框架也可以迁移到其他高风险、强监管的控制场景。不过要注意，结果来自高保真仿真，尚未在真实风场上部署。

## 一句话概括

提出 ZO-LBPG：不训练奖励模型，直接用人类偏好做零阶梯度估计，并保证训练过程中执行的每个策略（包括用于探索的扰动策略）都满足安全约束。

## 核心方法

- **对数障碍目标**：在最大化有用性的同时加上障碍项，策略越接近安全边界，被推回的力越强，用它代替原始-对偶方法里需要慢慢调整的对偶变量。
- **保守估计安全余量**：用"是否有害"的绝对判断估计离边界还有多远，并取置信下界，避免估计误差在边界附近被放大。
- **耦合采样**：同一个随机种子生成一对回答，降低单次梯度估计的方差，让每一步更新都能单独确认安全，而不只是平均意义上安全。
- **自适应步长**：根据余量和变化幅度的置信区间限制步长，保证更新不会越过约束边界。

## 关键结果

- 理论上以高概率保证所有迭代策略和探索策略都严格可行，并能全局收敛到近似最优的约束策略。
- 给出了轨迹数和人类查询数的样本复杂度，主导项与策略维度无关，轨迹复杂度与"有显式奖励"的安全探索方法持平。
- 在合成 CMDP 和语言模型对齐任务上，ZO-LBPG 的安全余量全程保持为正；原始-对偶基线虽然奖励差距更小，但反复越过约束边界。

## 为什么值得关注

RLHF 训练中的中间模型和采样回答本身就会被人看到、被评估，甚至会被部署，"最后可行"并不够。这篇工作把安全要求从最终策略扩展到整个数据采集过程，同时绕开了奖励模型容易被钻空子（reward hacking）的问题，为高风险场景下的安全对齐提供了有理论保证的思路。代价是样本和人类查询开销较大，离大规模落地还有距离。

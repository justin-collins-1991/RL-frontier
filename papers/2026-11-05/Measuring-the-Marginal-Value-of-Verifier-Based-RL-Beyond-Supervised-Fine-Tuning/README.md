## 一句话概括

这篇论文在一个可精确对比的受控环境里，单独测量"SFT 之后再做可验证奖励 RL（GRPO）"能多带来多少收益。结论是：分布内几乎没有提升，分布外只有很小但可测的提升。

## 核心方法

- 作者自建了 gpu-train-debug 基准：1,877 道合成的 GPU/LLM 训练故障诊断题，分 30 类。评分用确定性程序打分器，支持部分得分，没有奖励模型，也没有 LLM 裁判。题目做过防泄题加固，难度校准到中档模型能拿 0.60~0.75 分。
- 先做了一轮试点：Qwen2.5-3B 用 1,200 条标准示范做 SFT 后，hard 集从 0.31 提到 0.785；只做 15 步 GRPO 则几乎没变化。
- 根据试点结果，作者在正式实验前书面修改了研究问题，并预注册了几组对照：base、SFT、SFT+GRPO（60 步）、base+GRPO（60 步）。OOD 集在正式实验前完全没被碰过，结论措辞也事先定好。

## 关键结果

- SFT 在 hard/OOD 集上分别提升 +51.9 和 +51.5 分，吃掉了 75%~78% 的可提升空间。
- SFT 之后接 GRPO：分布内 +0.22 分，置信区间包含 0；OOD 上 +0.33 分，置信区间不含 0，提升集中在多故障交互类题目。
- 不做 SFT、直接从 base 训 60 步 GRPO：只提升 1.6~3.0 分，仍比 SFT 低约 50 分。
- 作者给出的解释：SFT 留下的错误大多是系统性的，同一道题多次采样错法相同，GRPO 组内几乎没有奖励差异，也就学不到东西。
- 整个研究的算力花费只有 8.69 美元，可完整复现。

## 为什么值得关注

业界默认"SFT 之后接 RL"会有额外收益，这篇论文直接测量了这部分边际价值。对分配后训练预算有实际参考意义：如果高质量示范已经接近饱和，RL 在分布内可能没什么可提升的空间。另外，"组内采样是否有分歧"可以作为上 RL 之前的廉价诊断指标。需要注意，结论只在小模型、合成任务和 60 步的规模下成立。

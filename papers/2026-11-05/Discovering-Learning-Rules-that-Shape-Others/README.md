## 一句话概括

把 DiscoRL 式"元学习发现更新规则"的思路搬到一般和博弈中，提出 DUOS：部署时只看自己的经验，就能自发表现出"塑造对手学习"的行为。

## 核心方法

- **规则与策略分离**：一个元网络（GRU+MLP）充当"更新规则"，每局结束后读取自己的轨迹（状态、双方动作、自身奖励）和自身收益矩阵，输出各状态下的策略调整量，再用它来更新内层策略网络。对手的参数、策略、学习规则和奖励全程看不到。
- **元目标**：最大化智能体整个"生命周期"（多局连续对弈）的累计回报，而不是显式要求它去塑造对手。
- **稳定训练**：如果对"双方共同学习"的过程求导，元梯度容易爆炸。因此改用似然比（REINFORCE 式）元梯度，在输出上加高斯噪声做探索，并用同一对手的多条生命周期回报作基线来降低方差。
- **抗剥削**：借鉴 PSRO，专门训练针对当前规则的"剥削者"，把它们加入对手池后继续优化规则。

## 关键结果

- 在 IPD、匹配硬币、Chicken、Stag Hunt、Coin Game 上与 LOLA、M-FOS 等方法循环赛对比，其中部分对手能看到对方的策略或参数。DUOS 的归一化平均分排名第 1，自博弈得分也排第 1。
- 在 IPD 上训练的规则可以零样本迁移到 Chicken 和 Stag Hunt。
- PSRO 阶段提升了对专门针对它训练的剥削者的抵抗力。

## 为什么值得关注

以往的对手塑造方法，要么部署时需要对手的特权信息，要么把学习算法藏在黑盒网络里、每个游戏都要重训。DUOS 首次在一般和博弈中"发现"出一条独立的智能体更新规则：部署门槛低、可迁移、输出可解释。这为多智能体系统（例如多 LLM 协作）中的去中心化合作提供了一条可行思路。

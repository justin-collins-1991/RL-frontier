## 一句话概括

把单像素成像里“下一次该打什么照明图案”的序贯实验设计问题改写成强化学习问题，训练出一个策略，根据当前对图像的后验认知直接输出下一个二值图案。

## 核心方法

- **问题**：单像素成像逐次用二值图案照明、单探测器测总光强。贝叶斯序贯实验设计希望每一步都选最能降低图像不确定性的图案，但 M 个像素对应 2^M 种候选，每步都现场优化根本算不动；贪心逐步选又会忽略长期收益。
- **做法**：把后验分布当作状态，把图案当作动作，把期望信息增益当作奖励，用 RL 离线训练策略。测量时只需前向推理一次，不再求解任何优化问题。
- **两种策略参数化**：类别策略给所有 2^M 个图案分配概率（精确但难扩展）；逐像素伯努利策略让每个像素独立决定开关（可扩展到更大图像）。
- **工程扩展**：用基于样本的近似后验替代精确后验、加入测量噪声，并针对生物医学场景引入照明能量的硬/软约束。

## 关键结果

在可精确计算信息增益、最优策略已知的受控场景下，学到的策略明显优于随机图案，并逼近最优设计；伯努利参数化在图像变大时仍保持可用。使用近似后验或存在噪声时性能只有温和下降，加了能量约束后框架依然有效。

## 为什么值得关注

这是一个“信息增益作奖励、后验作状态”的干净 RL 范式，把昂贵的在线优化摊销成离线训练，适用于任何组合爆炸的自适应采集问题（压缩感知、MRI 采样、主动传感等）。它也说明 RL 能做非贪心的长程规划，同时可以加入真实硬件约束。不过目前实验规模较小，能否扩展到真实大尺寸成像还需要验证。

## 一句话概括

首次把神经正切核（NTK）理论推广到带小批量采样和 TD 目标的 RL 训练，得到超宽网络价值函数演化的闭式解，并据此设计了用优化求解器做探索的方法。

## 核心方法

- **TD flow 建模**：经典 NTK 假设全量数据、固定标签，和 RL 不符。作者提出"TD 流"，允许每步的 mini-batch 和 TD 目标随时间变化（类似 DQN 的冻结目标网络），在无限宽 ReLU 网络下推出价值函数如何演化的闭式解。
- **良好的优化性质**：在有限状态-动作空间上，该解同时是强凸且光滑的，训练收敛性有保证。
- **求解器增强探索**：既然价值预测有显式表达式，就把"找当前预测 TD 误差最大的状态-动作对"写成数学规划，并加上环境约束来刻画可行状态，交给现成求解器一步全局搜索，把选中的样本作为新数据加入训练集（不同于 PER 的重复回放）。

## 关键结果

- 在确定性网格环境中，NTK 版 RL 训练稳定收敛，并能适应训练数据分布随探索发生的漂移。
- 基于闭式解的探索策略，样本效率明显优于标准深度 Q 学习基线。

## 为什么值得关注

深度 RL 的不稳定性长期靠经验调参，缺少分析工具。这项工作给出了一个可解析的"超宽网络代理模型"，可以低成本研究回放缓冲区、目标网络、采样策略等设计选择；同时展示了"白盒价值函数 + 优化求解器"做定向探索的新思路。不过目前只在小型确定性网格上验证，能否扩展到大规模或连续环境还有待观察。

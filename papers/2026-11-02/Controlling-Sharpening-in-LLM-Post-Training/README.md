## 一句话概括

pass@k 训练之所以能缓解 RL 的“锐化”（准确率升、覆盖面降），本质是按题目难度重新分配学习压力；把这种压力直接加到普通 @1 方法上，单条采样就能拿到 @k 的效果。

## 核心方法

作者推导出带 KL 正则的 pass@k / max@k 目标的闭式最优策略，发现它和普通 @1 最优策略形式相同，区别只在于 KL 系数变成了“随题目变化”的：模型本来就会的简单题，正则更强、少优化；很少做对的难题，正则更弱、优化压力更大。等价地，也可以不动正则，改为给难题的正确答案更大的奖励倍数、给简单题更小的倍数。

据此提出 KAPPO：先用参考模型采样一次，估计每道题的基础成功率，算出各题的自适应系数（结果可在多轮训练和调参中复用）；之后照常运行 GRPO、RLOO、PPO 等现有 @1 算法，只替换 KL 系数或奖励，其余训练流程不变。

## 关键结果

- 在数学推理和代码生成上，套用到多种 RL 方法后，调节 k 就能直接控制锐化程度。
- 只用单条 completion 训练，就能追平需要每题采 k 条样本的多采样 @k 优化器（如 PKPO），rollout 成本低得多。

## 为什么值得关注

它给出了一个与优化器无关的解释：@k 目标为什么能防止模型只在会做的题上“刷分”。工程上，KAPPO 几乎可以零成本接入现有 RL 流水线，把“保持多样性、攻克难题”变成一个可调的旋钮 k，对想提升 pass@k 或缓解 RLVR 探索停滞的团队很实用。

## 一句话概括

CALF-Wrapper 是一个部署期的"策略包装器"：把训练好的 RL 策略和一个有理论保证、但性能一般的保底控制器组合起来，既能拿到 RL 的性能，又保留"到达目标集并留在里面"的保证。

## 核心方法

- 输入有三样：现成的 RL 基础策略、同一 checkpoint 里的 critic，以及一个已被证明能到达目标的 fallback 控制器（PD、LQR、MPC、规则策略都可以）。
- 每一步把 critic 的估值当作类似 Lyapunov 函数的"进度指标"：如果价值有足够提升，就执行 RL 动作；否则按一定概率切回 fallback。
- 每步只需要一次 critic 前向、一次随机采样和几次标量比较。不需要动力学模型、在线学习或约束优化，也不用改训练代码。这个随机切换机制让性能和保证之间的权衡可以调节。

## 关键结果

- 理论上，在给定假设下，它继承了 fallback 的目标可达性，并给出收敛时间、以及偏离目标最大距离的概率界。
- 在四个复杂度不同的仿真控制环境中，和基础策略、fallback、PPO/TD3-Lagrangian 做了对比。它达到了实验中观测到的最高目标到达率，任务性能也保持有竞争力。敏感性和消融实验还给出了可以直接参考的超参数建议。

## 为什么值得关注

它给"黑盒 RL 策略怎么安全上线"提供了一条低成本的路：不用重新训练，挂上就能用，还能借用经典控制器的形式化保证。对已经有可靠传统控制器、又想用 RL 提升性能的工业场景（机器人、过程控制等）来说，比较实用。

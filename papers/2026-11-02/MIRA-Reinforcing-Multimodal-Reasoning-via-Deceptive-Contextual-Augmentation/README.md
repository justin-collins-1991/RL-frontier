## 一句话概括

MIRA 在多模态 RLVR 训练里故意塞入"看错了"的图像描述，逼模型学会发现并纠正自己的视觉误读，而不是顺着错误前提一路推下去。

## 核心方法

- **构造"陷阱"数据**：先让策略模型自己写一段和问题相关的图像描述，再由专家模型改动其中的关键细节（比如把时间 2:35 改成 3:50），得到看起来合理、实际错误的描述。
- **过滤无效扰动**：用一个只看文字的验证器检查，原描述能答对、篡改后答错的样本才保留，保证每个陷阱都真的会影响答案。
- **伪装成模型自己的输出**：把错误描述放进 assistant 的思考开头，模拟"我已经看错了"的真实场景。
- **组内反思触发**：GRPO 同一组 rollout 中，部分样本加入反思触发、部分不加，让模型通过组内优势对比体会到"回头核对图像"有收益，最终内化为默认行为。
- 不需要人工标注和 SFT 冷启动；训练时保留一部分原始数据，防止过拟合或策略退化。

## 关键结果

- 多个数学推理（in-domain）基准上，比基座模型平均提升约 7 个百分点。
- 没有额外加入通用视觉数据，在以视觉为主的感知基准上也有稳定提升，并优于多种现有方法。
- 消融实验分析了各组件各自的贡献。

## 为什么值得关注

多模态推理中约七成错误来自感知。以往方法多在"看得更准"上下功夫，MIRA 换了个思路，训练模型"看错后能自己改回来"。它只改训练数据和 rollout 方式，基本不动 RLVR 主流程，成本低、容易迁移，也为 RL 中引入对抗式上下文增强提供了一个可直接复用的做法。

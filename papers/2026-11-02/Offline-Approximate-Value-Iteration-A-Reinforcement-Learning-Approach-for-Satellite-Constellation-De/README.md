## 一句话概括

把 Walker 星座的部署过程（什么时候发射、发几颗、往哪个轨道面送、何时变轨爬升）建模成带随机故障的 MDP，再用离线近似值迭代（OAVI）求出策略。和滚动时域基线相比，期望成本更低，部署时间也更短。

## 核心方法

- **建模**：每个决策周期分三个阶段：①确认本次发射（目标轨道面、注入高度、卫星数量）；②决定哪些卫星从低注入轨道开始低推力爬升；③决定是否在未来排一次发射。状态记录各轨道面在注入轨道、爬升途中和已就位的卫星数，加上发射排期。发射、入轨、变轨三个环节都可能失败。成本包括发射费、燃料、缺星惩罚，以及完成部署的奖励。
- **求解**：状态和动作组合太多，精确值迭代算不动。作者改用基函数线性拟合价值函数，并在"决策后状态"上学习，也就是动作已经执行、随机结果还没出现的那个时刻，这样就把确定的决策效果和随机故障分开处理了。同时剪掉不可行或多余的动作。训练阶段用 ε-贪心做蒙特卡洛 rollout，再用最小二乘更新参数。到了线上，只需要一次贪心查询就能出决策。

## 关键结果

初步实验里训练能收敛。得到的策略在期望总成本和部署时长两项上都比滚动时域 MILP 基线低。框架也能应对部署中途目标星座规模的变化。

## 为什么值得关注

现有星座部署方法有两类：静态 MILP 默认信息完全已知，滚动时域重规划则只看眼前、而且每次重解都很耗算力。OAVI 把发射失败、卫星故障这些不确定性直接放进一个 MDP 里，策略离线算好，线上实时调用。这是近似动态规划在航天物流里一个比较少见的落地案例，对大规模星座的自主运营规划有参考价值。需要注意，目前只有初步结果，问题规模和轨道模型都做了简化。

## 一句话概括

不告诉智能体任何时空知识，只让它用量子探针最大化互信息，结果它学到的内部模型里能还原出闵可夫斯基时空的因果（光锥）结构。

## 核心方法

- **环境**：两个 Unruh–DeWitt 量子比特探测器与真空中的无质量标量场耦合。一个探测器固定，另一个在 (x, t) 二维网格上移动，选择自己与场相互作用的时空位置。
- **奖励**：两个探测器之间的量子互信息（做过变换），这是智能体能拿到的唯一信号。时空度规、因果关系都只是隐含在奖励分布里。
- **智能体**：基于模型的 RL。智能体要学一个预测环境的内部模型，再用规划器选动作。
- **读出几何**：训练完后，对规划器的表示加掩码，找出类似光锥的分支，再拟合一个二次型，得到度规分量。

## 关键结果

- 规划器的表示自发出现了时空特有的"零类（null）结构"，也就是光锥边界。
- 固定 g_xx = 1 后，拟合得到 g_tt ≈ −0.99988、g_tx ≈ 7.8×10⁻⁸，光锥斜率 ≈ ±0.99994，和标准闵可夫斯基值几乎一样。
- 光锥结构只能把度规确定到一个共形因子，所以还原出来的是局部共形几何，并非完整度规。

## 为什么值得关注

- 把 RL 智能体当成"操作性观察者"：几何概念并不是事先输入的，而是为了预测和行动得好才学出来的，给"时空从量子经验中涌现"提供了一个可计算的例子。
- 对 RL 和可解释性研究者来说，这是一个干净的案例：只用标量奖励训练，世界模型或规划器里就能长出可解释、可定量验证的物理结构。
- 局限：目前只做了平直时空、1+1 维切片、简单任务。弯曲时空和完整度规（包括共形因子）的还原还有待后续工作。

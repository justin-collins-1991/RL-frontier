## 一句话概括

AIRoA-0（A-0）完全不采集机器人数据，只用 16,151 小时手持夹爪演示训练双臂操作策略。它只靠两个腕部相机，就能在从未采过数据的新场地完成长时程、高精度任务，并且能直接部署到多种机械臂上。

## 核心方法

- **数据**：用开源手持夹爪 YUBI 采集。人拿着夹爪做任务就行，不需要机器人。每段数据都有任务级和子任务级两层语言标注，共 1065 万个子任务片段。
- **本体无关表示**：状态和动作都定义在夹爪上，视觉只用腕部相机，所以人手持时和装在任意机械臂上时，看到的输入是一样的。
- **预训练**：用两层语言指令告诉模型"整体做什么、现在做到哪一步"。再用"视觉证据预算"，在不标注注意区域的情况下，让模型自己学会看腕部画面里的关键区域。
- **后训练与推理**：增加任务阶段预测和近期运动记忆，以应对长任务里腕部视角信息不全的问题。推理时对预测的阶段做平滑，并用非均匀噪声调度把动作解码成连续的动作流。
- 全程不用遥操作、不用 RL、不用真机纠错，也不用仿真。

## 关键结果

- 在 Franka 双臂上测了 10 个任务，测试场地不在训练数据里。A-0 平均成功率 78%，最强基线只有 27%。四个基线是 π0.5、XR-1、GR00T N1.7、MolmoAct2，各自在每个任务上都调到了最优配置，而 A-0 所有任务只用同一套后训练配方。A-0 在每个任务上都是第一。
- 多数任务只需 3~6 小时后训练数据。能完成换扫地机器人拖布和滚刷这类持续数分钟的长任务。
- 运行中有人移动料盒，它能根据画面实时改道，把零件放进正确的盒子。
- 同一套权重不做任何调整，就能在 TX-G2 人形、OpenArm、UR 上运行。

## 为什么值得关注

这项工作说明，仅靠可以众包扩展的手持数据，就能训出强泛化的机器人策略，数据规模不再受机器人数量限制。论文开源了数据集（据称是目前最大的带指令手持夹爪数据集）、预训练权重和后训练配方。复现门槛很低：自己做夹爪、自己录任务，在单节点 8×H200 上 4 小时内就能完成后训练。值得注意的是，整个过程没有用 RL。这也引出一个问题：在这个基础上加入 RL，能不能进一步提升鲁棒性。

## 一句话概括

RLVR 能让模型在训练分布内学会正确的逐步推导，但题目一变难（OOD），模型会丢掉推导、改用暴力枚举，准确率随之大跌。加入"单解"的双射反函数任务一起训练，可以明显缓解这个问题。

## 核心方法

- **可控实验框架**：给出一个非双射字符串函数 f 的源码和输出 y，要求模型找出 k 个满足 f(x)=y 的输入 x，类似解方程、追 bug。OOD 设置包括：没见过的函数、更长的 y、要求更多解（更大的 k）。
- **策略可观测**：推理轨迹分成两类，一类是"推导"（一步排除一大批候选），一类是"枚举"（逐个试错）。
- **干预**：在训练中混入双射反函数任务（只有唯一解），让推导过程更确定。用这种方式训练的模型称为 MIXED，只用原任务训练的称为 MONO。
- **理论分析**：从"每一步推理能提供多少信息"的角度说明：即使只按最终结果给奖励，RLVR 也会隐式地给更高效的推理策略更多 credit。

## 关键结果

- MONO 在训练分布内准确率高、推导规范，但在 OOD 上整体转向低效枚举，准确率断崖式下降。
- 这种失败既不是基座模型能力不够，也不是 reward hacking，因为模型在训练分布内用的就是正确策略。
- 双射任务本身并不更难，与 OOD 测试的差距反而更大，但 MIXED 在训练分布内表现与 MONO 相当，OOD 上明显恢复了推导策略和准确率。
- 对隐状态做 probing、并逐条检查推理轨迹，也得到一致的定性证据。

## 为什么值得关注

看 RLVR 是否泛化，不能只看训练准确率，还要看模型实际用的是哪种推理策略。论文提供了一个可复现、能直接观察推理策略的诊断框架，也说明：精心挑选辅助训练任务、引导模型形成"信息密度高"的推理策略，可能比单纯堆数据或加过程监督更有效。这对设计数学、代码类 RL 训练的数据配比有直接参考价值。

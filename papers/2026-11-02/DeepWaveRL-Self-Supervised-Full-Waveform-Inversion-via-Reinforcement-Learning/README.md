## 一句话概括

把地震全波形反演（FWI）改写成单步强化学习问题：策略网络输出整张速度图，正演模拟器只负责打分。整个训练既不用真实速度图，也不用正演算子的梯度。

## 核心方法

- **问题建模**：输入地震数据作为状态，网络对每个像素输出离散速度的概率分布，采样出的整张速度图就是一个动作。正演模拟出地震记录后，与观测数据的误差换算成一个全局标量奖励。
- **GRPO 式优化**：每个输入采样一组速度图，在组内做奖励归一化得到优势，不需要价值网络，也去掉了 KL 约束。
- **三个稳定化技巧**：(1) 把重要性比率放在整张图层面计算，与奖励的粒度对齐，配合离散动作空间降低梯度方差；(2) 对奖励做保号对数变换，压住强直达波能量，让深部的弱反射也能提供学习信号；(3) 先用迁移学习给策略注入结构先验作为初始化，帮助越过局部最优。
- **测试时优化**：推理阶段只需要观测数据和正演算子，可以针对单个样本继续用同一个目标微调。

## 关键结果

在 OpenFWI 的 CurveVel-A 上，只靠标量奖励就接近有监督的 InversionNet：MAE 0.0527 vs 0.0409，RMSE 0.1012 vs 0.0944，SSIM 0.8601 vs 0.8796。借助迁移得到的先验，还能较高效地泛化到 FlatFault-A、CurveFault-A 这类断层结构更复杂的数据。

## 为什么值得关注

工业界的正演代码往往是不可微的黑盒，这项工作说明这种场景下也能做自监督反演。从 RL 角度看，它把 LLM 圈常用的 GRPO/GSPO 思路搬到了高维空间输出任务上，并直面“单个标量奖励如何分配到成千上万个像素”这一信用分配难题，对其他科学反问题有参考价值。

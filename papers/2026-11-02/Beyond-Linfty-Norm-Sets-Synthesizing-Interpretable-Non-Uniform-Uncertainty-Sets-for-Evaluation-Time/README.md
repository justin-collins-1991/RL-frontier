## 一句话概括

不再用"所有维度一刀切"的 L∞ 扰动球来评估 RL 策略鲁棒性，而是根据"允许回报下降多少"，在线为每个状态、每个维度算出各自的扰动预算（PD-NUUS）。

## 核心方法

- **问题**：连续控制中，各状态维度的物理含义和对策略的影响差别很大（如 Hopper 的高度、角速度一扰就崩，躯干角度却几乎不敏感）；同一维度在机器人"快摔倒"时也比"站稳"时更脆弱。固定 ε 的 L∞ 球既不真实，ε 本身也缺乏可解释性。
- **思路**：把不确定集换成按维度缩放的"盒子"，预算随状态变化。目标是让盒子尽量大，约束是最坏情况下的回报下降不超过用户设定的容忍度 β。
- **可解**：原约束依赖扰动后策略的状态分布，没法直接算。作者借鉴离线 RL 的做法，用"原策略的优势函数 + 一个限制扰动后策略不偏离原策略太远的 KL 惩罚"作为替代约束，得到闭式解，可以在评估时对任意预训练策略在线合成，不改训练流程。

## 关键结果

在多个连续控制环境、多种训练算法和多种状态攻击下，PD-NUUS 能清晰揭示策略在不同状态、不同维度上的敏感度差异，同时实际回报下降大体被控制在设定的容忍度附近（控制效果"中等可靠"，并非严格保证）。

## 为什么值得关注

它把扰动预算从"拍脑袋的 ε"变成了"可以接受多少性能损失"，让鲁棒性评估更可解释，也能跨算法、跨环境比较。对机器人等部署场景，它还能直接指出策略"何时、在哪个传感器维度上"最脆弱，为传感器冗余设计和针对性鲁棒训练提供依据。

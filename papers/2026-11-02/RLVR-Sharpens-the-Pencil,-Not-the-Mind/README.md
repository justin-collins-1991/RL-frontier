## 一句话概括

作者跟踪了 RLVR 训练的全过程，发现它只是让模型更常先给出自己最好的解法，并没有改变模型内部对推理的理解。

## 核心方法

以 OLMo-2-1B 在 GSM8K 上公开的 13 个 RLVR checkpoint 为对象，全程只做推理、不训练：
- 行为层：每个 checkpoint 都测 pass@1 和 pass@256，看首次答对率和"多采样能覆盖多少题"；
- 表征层：往做对的题目里人为植入三类算术错误，在各层隐状态上训练线性探针，看模型内部识别错误的能力是否随训练变强；
- 对照组：用同一套探针去区分早期和晚期 checkpoint，证明这套方法确实测得出变化。

## 关键结果

- pass@1 从 58.0% 升到 61.3%，pass@256 从 94.5% 升到 96.9%，可解题的范围没有收窄；
- 错误检测探针的 AUROC 在 13 个 checkpoint、3 类错误上都稳定在 0.80~0.84，波动比置信区间还小，换层、换读取位置结论不变；
- 唯一明显的变化出现在最终答案 token 上，区分早晚 checkpoint 的 AUROC 达到 0.93，而在中间推理步骤上接近随机。

## 为什么值得关注

以往支持"sharpening"的证据要么只看输出，要么只比较训练前后两个端点，这篇首次逐个 checkpoint 看模型内部，给出了更直接的证据。对工程也有用：在 base 模型上训好的错误检测器/验证器有望直接用到 RL 后的模型上。局限是只测了 1B 模型和小学算术这一个任务。

## 一句话概括

AffToM 是一个视频情感心智理论（ToM）基准，考察模型能不能在多人互动、各方掌握的信息不对等且不断变化的情况下，递归推断出“A 认为 B 觉得 C 是什么情绪”。作者同时提出 AffToM-R1，用 SFT 加强化学习来提升这项能力。

## 核心方法

- **两类任务**：IAR（个体情感推理）根据事件和社会情境推断单个人的情绪；MPAR（多方情感推理）需要沿着嵌套的“信念—情绪”链做二阶、三阶推理，而且新证据出现后要更新判断。
- **数据构建**：先用多智能体从视频中抽出事件、人际关系和心理状态，构建动态角色交互图，再基于图按参与者组合、信息不对称、更新深度和递归阶数可控地生成问题。生成的问题经过“逻辑正确性 + 干扰项区分度”的双标准迭代打磨，最后人工校验。测试集 1,922 条，训练集 19,759 条。
- **AffToM-R1**：两阶段后训练。先做 SFT，再做 RL，奖励来自“视角感知”的评分细则（rubric），引导模型站在指定角色的视角推断情绪。

## 关键结果

- MPAR 难度很高：即使是评测中最强的 MLLM，准确率也不到 60%。
- AffToM-R1 的 MPAR 准确率比其基座模型高 13.38 个百分点。
- 评测同时包含选择题和开放式问答两种形式。

## 为什么值得关注

现有基准大多把高阶信念推理和情绪识别分开测，AffToM 把两者合到一起，并加入了信念随时间更新这个维度，能更清楚地区分“真的懂人心”和“只会看表情”。对 RL 方向来说，它给出了一个在主观、难以直接验证的社会推理任务上用 rubric 做奖励的实际例子，可以迁移到其他开放式推理任务上。

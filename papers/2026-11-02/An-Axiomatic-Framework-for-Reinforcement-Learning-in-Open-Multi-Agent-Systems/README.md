## 一句话概括

在只有部分智能体可控的开放多智能体系统里，把 Shapley 值的三条公理当作结构约束来学习个体价值函数，给算法设计提供了有理论依据的方法，并且可以直接套在现有 RL 算法上提升效果。

## 核心方法

- **NAHT 分解**：把团队价值拆成两部分：一是"内部协作"，只发生在可控智能体之间；二是"外部配合"，涉及不可控的队友。后者是开放系统独有的部分，当所有智能体都可控时它就消失，问题退化为常规的协作式 MARL。
- **公理化学习**：作者没有直接套用 Shapley 值的计算公式，而是在训练中强制个体价值函数满足效率性、对称性、线性三条公理。理论上可以证明，这样学出来的结果正好就是 Dec-POMDP 中的 Shapley 值。他们还发现，线性公理推出的结构等价于截断的 TD(λ)，这为 n 步回报提供了一种博弈论层面的解释。
- **两个通用模板**：Shapley Machines 满足全部三条公理；Banzhaf Machines 放宽效率公理，对应的是 Banzhaf 指数。两者都能直接套在 IPPO、POAM 等现有算法上。

## 关键结果

在改造成 NAHT 设定的 MPE 和 SMAC 基准上，以 IPPO、POAM 为基础算法，套用这两个模板后学习效率稳定提升，遇到没见过的队友类型和协作习惯时泛化也更好。在部分场景下，放宽某条公理（即 Banzhaf 版本）效果反而更好。

## 为什么值得关注

智能电网、机器人集群等实际场景大多是"开放"的：队友不受控制，人数也会变化。这篇工作把合作博弈论和 RL 价值学习严格地联系起来，让个体价值函数的设计有了依据，不再只靠经验和启发式。它给出的是即插即用的算法模板，代码也已开源，工程上落地成本低。另外，用公理解释 TD(λ) 的视角对设计时序差分方法也有启发。

## 一句话概括

模型设定有偏差（model mismatch）时，数据并不是越多越好。F2I 为高斯过程（GP）设计了一种影响度量，主动“遗忘”会拖累目标区域预测的样本，用来改进贝叶斯优化、基于模型的 RL 和直推式学习。

## 核心方法

- **目标**：没有目标区域 A 的标签，就以“A 内预测不确定性最小”为目标，挑出训练数据的最优子集。
- **影响度量**：把每个样本对预测方差的贡献拆成两部分：一是对 A 内认知不确定性（epistemic）的贡献，二是对全局噪声估计（aleatoric）的贡献。有些样本虽然能改善全局拟合，却会抬高噪声估计，或抵消 A 内的方差下降。
- **高效计算**：把离散的留一法放松成连续的“移除方向”，用影响函数近似删掉某个样本的效果，不必对每个候选样本重新训练模型。
- **贪心删除**：每轮删掉最有害的样本。论文给出了相对最优子集的近似界和近似最优性保证。
- **序列扩展**：把 BO 和 RL 看成目标区域不断变化的序列直推学习，得到 Forgetful BO 和 Forgetful RL。

## 关键结果

在直推式学习、贝叶斯优化和基于模型的 RL 等多类任务上，F2I 都有显著提升。以道琼斯数据为例，普通同方差 GP 会把有害结构当成噪声吸收，导致目标区域的预测很不确定；F2I 删掉这些点后，预测更准，置信度也更高。如果有害样本出现在优化早期，F2I 的收益尤其明显。

## 为什么值得关注

主动学习一直只研究“下一步采哪个点”，F2I 补上了另一半：“已经采到的数据里该删哪些”。这个思路有理论保证，可以直接接进现有 GP 流程，不需要换更复杂的似然或噪声模型。对用 GP 做探索、做规划的 BO 和 model-based RL 来说，它是提升鲁棒性的一个实用工具。

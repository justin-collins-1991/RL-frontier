## 一句话概括

让 LLM 先判断一道题该用哪种“解法范式”（CoT、写代码、SMT、PDDL 规划、MILP 优化），需要时再生成结构化建模指导，最后才执行求解。

## 核心方法

把解题拆成三步：

- **SteerLM（选路）**：读题后输出“范式 + 模式”，模式指要不要额外指导。先 SFT，再用 GRPO 强化学习训练，奖励来自不同范式/模式组合的实际执行结果。
- **GuideLM（建模）**：每种范式各有一个专家模型，用 SFT 训练，按固定模板产出结构化建模方案，例如 MILP 的决策变量、约束和目标。训练数据只保留确实能提升下游执行效果的指导。
- **ExecuteLM（执行）**：通用 LLM 根据选定的范式和指导写出推理过程、代码或求解器调用，再交给对应执行器跑出答案。

和固定提示模板不同，这里“用什么范式”和“怎么建模”都是按题目学出来的。

## 关键结果

- 基于 Qwen3-8B，在 5 类问题、13 个基准、66 个领域上评测，平均准确率从 38.4% 提升到 72.9%。
- 比最强的大模型提示基线 GLM-5 高 11.7%。
- 消融实验显示，选路和建模指导两个模块都有贡献。
- 训练好的 SteerLM 和 GuideLM 换到别的执行模型上依然有效。

## 为什么值得关注

以往的路由类工作大多只在文本和代码之间做选择，或者只接一种求解器。AlgoPilot 把经典的“算法选择”思路搬进 LLM 推理，用 RL 学习跨多种计算范式的策略选择，并把“选范式”和“建模”分开处理。它可以作为一个可迁移的“推理调度层”，加在已有模型前面，用小模型配合外部求解器就能获得接近甚至超过大模型的效果，工程上很实用。

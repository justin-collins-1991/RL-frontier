## 一句话概括

Axion 1.0 用“两段轻量 SFT + 一段 RL”的极简流程训练智能体基座模型，不做 mid-training、DPO 或在线蒸馏，仍能在多项 agent 基准上接近商业前沿模型，并开源了完整训练配方。

## 核心方法

- **SFT 第一阶段：自包含推理。**以数理化生、计算机等公开题目为种子，先通过“组合”把题目变难；如果基座模型仍然能做对，就参考它的成功解法，从四种操作中随机选一种继续加难：加一步推理、把数值换成参数、扩大范围让暴力枚举失效、引入分情况讨论。最后只保留答案正确的解题轨迹，约 1.08 万条。
- **SFT 第二阶段：依赖工具的推理。**从天文、生物、化学等结构化数据库出发，按“筛选、选择、计算、转写成自然语言”的流程自动生成可验证的问题。解题时屏蔽数据库并隐藏答案，迫使模型使用 search、visit、python 等工具。只保留验证正确的轨迹，约 7.5K 条。
- **RL 阶段：**在 agent 轨迹上做强化学习，进一步提升长程推理和与环境交互的能力。

## 关键结果

在 Humanity's Last Exam、SEAL-0、HiPhO、FrontierScience 等推理、科学、搜索和智能体基准上，122B 和 35B 两个版本都与主流开源模型及 GPT、Claude、Gemini 等商业模型相当，部分基准更好。SFT 数据总量不到 2 万条。

## 为什么值得关注

当下 agent 模型的训练流程越来越繁杂，这篇工作说明，把功夫下在数据难度和可验证性上，配合简单的阶段划分，就能得到很强的效果。它的开源程度也超出“只放权重”：数据构造、过滤、验证、提示词和训练代码全部公开，复现和迁移的成本因此大大降低。其中“根据基座模型的解法有针对性地加难”的数据合成思路，也可以直接借鉴到其他 RL/SFT 数据管线中。

## 一句话概括

这篇论文用数值实验研究：面对一个动力学未知、可能本身不稳定的连续时间随机线性系统，要多少数据、多大激励，才能学出一个让系统稳定下来的反馈控制器。

## 核心方法

方法本身很朴素，不需要任何先验的镇定控制器。做法分三步：先给系统注入分段恒定的高斯随机输入来"激励"它，记录一条或多条轨迹；然后用连续时间最小二乘一次性估计系统矩阵 A 和输入矩阵 B；最后把估计值代入标准 LQR（Riccati 方程）得到反馈增益。"失败"指这个增益没能让真实系统稳定。作者用一个经验缩放关系来组织实验：失败概率的对数，与总观测时长、可控性成正比，与维度、噪声方差成反比，与激励强度只是对数关系。

## 关键结果

- 在有两个不稳定模态的间歇反应釜基准上，辨识误差的平方随总观测时长（轨迹数 × 轨迹长度）成反比下降，失败概率则随它指数下降。
- 所以一条长轨迹和多条总长相同的短轨迹效果差不多，即使系统不稳定、状态在指数增长。
- "信号饱和"：加大激励强度，收益只按对数增长，因为输入太强时状态和输入高度相关，难以把 A 和 B 区分开。
- 刻意削弱对某个稳定模态的激励后，辨识精度明显变差，但镇定成功率基本不变：镇定不需要把整个模型辨识准。

## 为什么值得关注

对做基于模型的 RL 或自适应控制的工程师，这篇给了实用的数据预算参考：重点看总采样时长，不用纠结怎么切分轨迹；激励不是越大越好；数据应该花在不稳定的方向上。这些结论都还只是实验观察，没有理论证明，但为连续时间下"从零学会镇定"的理论研究指了方向。

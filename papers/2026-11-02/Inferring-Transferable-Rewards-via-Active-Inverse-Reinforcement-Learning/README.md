## 一句话概括

把逆强化学习（IRL）做成“主动选环境”的问题：每轮挑一个最能补上奖励不确定性的环境动力学请专家示范，用更少的示范学到能迁移到不同动力学的奖励函数，并给出理论保证。

## 核心方法

- **问题背景**：只在一个环境里看专家示范，奖励只能辨识出一部分，换个动力学就可能失效；在多个差异足够大的环境里收集示范才能消除这种歧义。但专家示范很贵，改环境配置（摩擦、质量、路况等）相对便宜。
- **两阶段算法**：
  1. **热身阶段**：轮流在所有可选环境里各要一批示范，先得到一个足够可靠的奖励估计；
  2. **主动阶段**：基于当前估计构造奖励的“置信椭球”，哪个环境能在椭球最宽、信息最少的方向上提供最多信息，就去那里要示范。
- 奖励设为已知特征上的线性函数，估计时只在各环境可辨识的子空间里更新，避免噪声沿无法辨识的方向漂移。

## 关键结果

- 理论：在 n 轮示范后，跨所有可选环境的最坏迁移误差约为 O(1/n)，且**与可选环境数量无关**；对任意未见过的动力学也成立（多一项不可消除的偏差）。这是首个带样本复杂度保证的主动 IRL 动力学选择方法。
- 实验：相比行为克隆、常规 IRL 以及已有的动力学设计方法，达到同等可迁移性所需示范最多少约 5 倍，在未见环境上泛化最好。

## 为什么值得关注

机器人、自动驾驶仿真等场景里，人类示范是主要成本。这篇工作给出了一个有理论支撑、思路简单的策略：先均匀摸底，再按信息增益挑环境，能直接用来规划“在哪些配置下采示范”，省示范预算的同时让学到的奖励更稳健地迁移。

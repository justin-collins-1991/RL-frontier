## 一句话概括

目标环境数据少时，DFQI 在每一步拟合 Q 迭代里同时学目标和源任务，借用相关环境的数据，让离线 Q 函数估得更准、学到的策略更好。

## 核心方法

已有的迁移 FQI 一般分两步：先用源数据拟合一个固定的“参考”，再拿目标数据估一个修正项。任务差异大时，这个修正很难靠少量目标数据估准，误差还会沿着 Bellman 迭代一路往后传。DFQI 把两步合成一个联合优化：每轮迭代中，各任务先用自己上一轮的 Q 估计构造回归目标，再一起拟合目标和各源任务的系数，并用 L1 惩罚把目标系数拉向“按样本量加权的源系数聚合”。这样，参考和修正在同一轮里一起确定，修正项保持稀疏，每个任务也保留自己的拟合函数。

## 关键结果

- 理论：在 sieve（基函数展开）近似下，分别对“转移核相同、奖励不同”和“转移核也不同”两种情形给出了目标 Q 估计误差界和策略价值损失界。误差可拆成三部分：近似误差、由源加目标总样本量决定的统计误差、取决于差异大小与稀疏度的目标修正误差。
- 实验：在蒙特卡洛模拟和基于真实数据的半合成研究中，目标数据有限时，DFQI 改善了 Q 估计和策略表现。

## 为什么值得关注

营销、医疗这类场景经常是目标数据少、相关历史数据多。DFQI 给出了一种有理论保证的“联合借力”做法，可以缓解两步法的固定参考偏差和误差累积问题，对小样本离线 RL 的落地有直接参考价值。

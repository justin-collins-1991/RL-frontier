## 一句话概括

用流匹配建模回报分布，并在**每一个噪声层**都用贝尔曼一致性做监督，从有限数据里榨出更多学习信号，让价值估计更准、分布不再塌缩。

## 核心方法

- **问题**：离线 RL 中每条转移只给一个即时奖励，TD 目标又依赖自身估计；数据少、奖励稀疏时价值函数很难学准。
- **已有做法的不足**：基于流匹配的分布式价值方法，要么只在流的终点（去噪后）施加贝尔曼目标，监督稀疏；要么在所有噪声层硬套"干净"的贝尔曼方程（在初始噪声处是错的），或只沿共享同一初始噪声的耦合路径约束。结果常是学到的回报分布塌缩成一个点。
- **Value Forcing**：在每个噪声层，用下一状态的边缘回报分布去监督当前状态的边缘回报分布。为此设计了带**高斯修正项**的"流贝尔曼算子"，保证每个噪声层都有唯一不动点：起点保持高斯噪声，终点恢复标准分布式贝尔曼方程。
- **两个算法**：VF（actor-critic 版）和 IVF（基于 expectile 加权流匹配的隐式价值学习，类似 IQL 思路，理论上随 expectile 增大逼近数据内动作的最优值）。

## 关键结果

- 在 26 个长时程离线任务（OGBench 20 个 + OCBench 6 个）上，VF/IVF 均优于以往的价值学习方法，包括其他基于流的分布式 critic。
- 回报分布估计明显更准，且不会出现先前方法的分布塌缩。
- 全量数据下与 SOTA 持平，**数据越少优势越大**。

## 为什么值得关注

机器人等真实场景数据贵、奖励稀疏，"如何从同样的数据里拿到更多监督"是实际痛点。这篇工作指出，流匹配的中间噪声层本身就是可以利用的额外监督位点，但前提是一致性要定义对。这个思路可以直接迁移到其他生成式 critic 上，也给分布式 RL 和扩散/流模型的结合提供了更扎实的理论基础。

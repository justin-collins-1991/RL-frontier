## 一句话概括

用户问题信息不全时，现有大模型几乎都直接"猜"着回答。本文构建了 VagueBench 基准，并提出离线强化学习方法 DialogGRPO，训练模型判断该不该追问、该问什么。

## 核心方法

- **VagueBench**：从真实商用助手日志中筛出 4,930 条信息完整的种子问题，把每条拆成"意图"和"细节"两类信息单元，再有控制地删掉对应的语言线索，得到"意图模糊"和"完全模糊"两种变体。缺了哪些信息是确定已知的，所以能精确评估模型问得对不对、问得是否高效。模拟用户只在被问到语义匹配的问题时才透露对应信息。
- **DialogGRPO**：把多轮追问过程预先展开成一张对话状态有向无环图（DAG）。每个节点上的若干候选问题组内比较（GRPO 式），每一轮的奖励由"当轮获得的信息增益"和"对后续回答的前瞻价值"两部分组成。这样能做到逐轮的细粒度信用分配，训练时也不需要在线调用用户模拟器。

## 关键结果

- 从 8B 到前沿闭源共 7 个模型，面对信息不全的问题时主动追问的比例都不到 11%，而且模型变大也没有明显改善。
- DialogGRPO 在 88% 以上的模糊问题上能问出缺失信息，信息获取效率和最终回答覆盖度都大幅提升；面对信息完整的问题时不会过度追问。
- 优于提示工程和测试时扩展（test-time scaling）类基线，并能零样本迁移到 MultiWOZ 2.4 和 AmbigQA。

## 为什么值得关注

"不问就猜"是助手类产品的常见痛点，本文给了一套可复现的评测方法和一套低成本的训练方法。离线 DAG 加逐轮稠密奖励的做法，规避了多轮 RL 中在线模拟用户成本高、只有整段对话级奖励导致信用分配粗糙的问题，也可以推广到其他多轮交互型 agent 的训练。

## 一句话概括

针对“上层学奖励、下层按奖励训策略”的双层强化学习，本文给出一个单循环、纯一阶、带真实神经网络 actor 和非线性 critic 的算法，并在连续状态空间下证明了 Õ(ε⁻²) 的样本复杂度。

## 核心方法

- **不再假设均匀 PL 条件**：作者先举反例说明，即使策略平滑、价值可精确表示，下层问题也可能有次优驻点，所以以往依赖 PL 的分析并不可靠。本文改为用固定参考策略的 KL 正则，结合初始化条件，推出“局部曲率”，并证明训练过程始终停留在这个良好区域内。
- **纯一阶的超梯度估计**：不求 Hessian 逆，而是同时维护一个基准策略和一个轻微扰动的策略，用两者的梯度差来近似“奖励变化引起的策略响应”。
- **共享轨迹降噪**：两个相近策略在同一批（加权）轨迹上评估，扰动越小噪声也不会被放大。
- **成对 critic**：两个 critic 一起训练，直接控制它们误差的“差值”，保证归一化后的估计依然稳定。

## 关键结果

- 在 actor、critic 与奖励同时更新（含 critic 训练、偏好采样开销）的情况下，达到 ε 级平稳点只需 Õ(ε⁻²) 样本，优于此前连续状态方法的 Õ(ε⁻³) 和表格方法的 Õ(ε⁻³)～Õ(ε⁻³·⁵)。
- 适用于连续状态、有限动作，并给出了一个满足全部假设的连续状态构造实例。

## 为什么值得关注

奖励模型学习和 RLHF 本质上就是双层 RL。这项工作让理论分析更贴近实际的 actor-critic 训练：一阶、单循环、用真实神经网络，还指出了常用 PL 假设的问题。它给“边学奖励边调策略”提供了更可信的收敛与样本效率保证。不过结论依赖初始化、特征激励、价值可实现性等较强条件，动作空间也限于有限情形。

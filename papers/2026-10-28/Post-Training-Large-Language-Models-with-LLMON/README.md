## 一句话概括

IBM 用 LLMON 结构化格式做后训练，教模型区分“要执行的指令”和“只需读的数据”，大幅降低间接提示注入成功率。

## 核心方法

- 结构化输入：用保留特殊 token 把上下文切成带类型和 ID 的块，普通文本无法拼出这些边界。
- 执行绑定：只有 `exec` 块按 ID 引用的指令才算数，文档、工具返回等输入都只是材料。
- 干扰增强：加入竞争指令和无关数据，目标输出不变，迫使模型依据绑定而非位置或语气。
- 训练：在 Granite-4.1 3B/8B 上用 4.6B token 先做 SFT，再做 RL。

## 关键结果

- 注入基准攻击成功率从 53%~100% 降至 0.02%~5.6%。
- 能力均分 3B 持平，8B 降 1.4 分。
- 红队测试对间接攻击的鲁棒性达 80%~85%，直接和多轮攻击仅 28%~37%。
- 中后层注意力明显更聚焦目标指令，但论文未证明因果。

## 为什么值得关注

它说明不改架构、只靠标准后训练就能教会模型指令与数据隔离，对 RAG 和 Agent 场景很实用。代价是上下文增长约 7%~15%，且需要采用新格式。这是学习到的行为而非硬保证，只防不可信输入，应作为多层防御之一。

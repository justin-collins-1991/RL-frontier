## 一句话概括

很多只能采样、无法算概率的问题，真正要算的是“在第三个分布 p* 下取平均的对数密度比”（ELDR）。作者指出，常见做法“先学 p0/p1 的密度比再在 p* 上取平均”有根本缺陷，应把 ELDR 当作单独的估计目标来处理。

## 核心方法

- **统一视角**：实验设计、仿真推断、模型比较，以及 RL 里的 KL 约束、离线 RL/行为克隆、模仿学习的占用度匹配，都可以改写成 ELDR 估计问题。
- **理论下界**：有限样本下，ELDR 置信区间的宽度会受到 p0、p1、p* 之间 KL 散度的制约。即使密度比学得完全准确，只要 p* 离 p0/p1 很远，估计误差也压不下来。
- **p\* 感知的退火**：现有路径式 DRE 只在 p0 和 p1 之间插值。作者改为让退火路径经过 p*，使训练数据里出现逼近 p* 的样本。另外还提出一个基于随机插值的基线方法 VFM。

## 关键结果

在包含文本、图像、物理模拟等真实数据生成模型的新基准上，多种 DRE/KL 估计基线换成 p* 感知版本后，ELDR 估计误差有所下降。

## 为什么值得关注

RL 里的 KL 正则、策略约束和离线策略评估，经常直接把一个密度比估计器在新分布上做平均来用。本文说明这种用法在分布偏移大时本身就不可靠，并给出了一个简单的改法：训练时让模型见到它在评估时要面对的分布。

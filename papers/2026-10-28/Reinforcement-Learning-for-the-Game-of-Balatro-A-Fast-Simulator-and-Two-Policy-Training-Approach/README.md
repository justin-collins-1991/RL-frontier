## 一句话概括

作者为卡牌肉鸽游戏 Balatro 搭了一条完整的 RL 流水线：先做一个与真实游戏自动对拍的高速 Rust 模拟器，再把游戏拆给“出牌”和“商店”两个 PPO 策略分别学。这样一来，智能体能稳定打过第一关，平均能推进到第 3 个 ante（满分 8）。

## 核心方法

- **快且准的模拟器**：游戏逻辑用 Rust 实现，再通过 Python 绑定接入训练。作者借助 BalatroBot 让模拟器和真实游戏客户端逐步比对状态，发现分歧就记录下来，积累成回归测试，从而避免旧版 gym 带来的“版本漂移”。
- **精简接口加动态掩码**：完整接口约有 3000 个动作、2 万维观测，训练时再裁剪成一个子集。每一步都会根据游戏规则屏蔽非法动作，比如手里没有的牌、买不起的商品。
- **双策略分工**：两个策略都能看到完整状态，但只在各自的阶段行动。出牌策略负责战术层面的过关，商店策略负责战略层面的构筑和经济。奖励按阶段分给对应的策略，同时显式地给对方一部分功劳，用来缓解长时程的信用分配问题。

## 关键结果

- 联合训练过程中出现了明显的“相变”：第一关通关率收敛到 99% 以上，平均回报大约提升了一个数量级，最终平均能推进到约第 3 个 ante。
- 单策略基线使用相同的奖励，却在“贪心乱花”和“一味囤钱”两种失败模式之间来回摇摆，始终没能稳定通过第一关。

## 为什么值得关注

Balatro 同时具备超大且随状态变化的动作空间、长时程稀疏奖励和强随机性，是很好的 RL 试验场。这篇工作给出了一个可复现的强基线，也说明在这类游戏里，模拟器的保真度才是真正的瓶颈。它还把剩下的差距定位到长期战略规划上，而不是单局出牌。按游戏阶段拆分策略的思路，也可以借鉴到其他构筑类、多阶段决策任务中。

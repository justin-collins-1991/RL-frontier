## 一句话概括

离线 RL 里不再只让策略"动作像数据"，而是让策略"导致的下一状态像数据"，并用一个高斯隐空间里的闭式 KL 把这件本来算不了的事变得可算。

## 核心方法

- **问题**：TD3+BC、BRAC、BEAR 这类方法只约束动作分布。可在对动力学敏感的区域，动作只偏一点，下一状态就可能差很多，智能体会被带出数据覆盖范围。
- **理想目标**：直接约束策略诱导的下一状态分布。但这要知道真实动力学，离线条件下做不到。
- **StBR（结构化行为正则）**：引入隐变量 z，假设 (s,a)→z→s′。作者证明隐空间分布的 KL 是"后果分布 KL"的上界，所以只约束隐空间就够了。
- **State Belief Gaussian Fitting**：基于变分信息瓶颈训练编码器和解码器，让 z 只保留预测下一状态所需的信息；同时把行为数据的 z 拟合成一个单峰高斯"状态信念"。这样策略和行为策略之间的散度就有闭式解。单峰只是对隐空间的几何约束，并不假设真实动作分布是单峰的。
- **效果**：隐空间编码了动力学，在敏感区域动作的小偏差会被放大成大的隐空间偏移，所以惩罚会自动收紧；在不敏感区域则保持宽松。

## 关键结果

- 理论上，代理目标与真实后果散度之间的差距有界。
- 在多个主流离线 RL 基准上，StBR 的表现优于现有行为正则化方法。论文发表于 NeurIPS 2026，代码已开源。

## 为什么值得关注

它把离线 RL 的保守性从"动作空间"挪到了"后果空间"，直接回应了分布偏移的根源：状态偏离数据。方法不需要显式估计动力学密度，只多加一个表示学习模块，就能替换现有的 KL/MMD/MSE 正则项，接入成本低。对机器人这类动力学敏感的场景尤其有参考价值。

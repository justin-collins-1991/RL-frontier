## 一句话概括

GUIDER 把临床指南里的条件决策流当作过程监督，同时训练"决策流生成器"和推理策略，让模型既遵循指南，又能答对。

## 核心方法

用指南做过程监督有两个难点：一是推理路径符合指南，不代表对这个病人的答案就对（路径与答案脱节）；二是同一个临床决策往往有多条合理路径（路径多样）。GUIDER 的做法：
- **控制器**：从指南衍生的监督中学习，生成多条合理的决策流；
- **策略模型**：针对每个病例输出决策流和最终答案；
- **过程奖励**：拿策略的路径和控制器给出的多条候选流比对，不再只认一条参考路径；奖励只在答案正确时生效，防止"路径像、答案错"也拿分；
- **联合训练**：控制器和策略一起更新，过程监督随策略能力同步变化。

## 关键结果

- MedGUIDE 上，Qwen3-14B 加权准确率 82.5、指南遵循度 73.5，比最强的临床 RL 基线分别高 3.3 和 3.1 分；
- 在 Qwen3-14B 和 Gemma4-12B 上，域外基准 AMEGA-LLM、RealMedQA、CancerGUIDE 的结果均优于 CRPO、MRPO、FaithMed。

## 为什么值得关注

过程奖励通常默认只有一条标准路径，但在医疗、法律、合规流程这类场景中，合理路径往往不止一条。GUIDER 用"多参考路径 + 答案门控"同时处理这两个问题，避免了 SFT 只学一条轨迹、反而拉低准确率的情况。对需要按规范推理的领域做 RL 训练，这个奖励设计可以直接借鉴。

## 一句话概括

Skill-Uni 让同一个 LLM 在生成过程中自己决定"要不要找技能、找什么技能、怎么用技能"，并用强化学习按最终任务结果把检索和使用一起优化。

## 核心方法

- **问题**：现有技能增强方案是"检索器 + LLM"两段式，各自优化。作者实测发现，检索器变强后，检索准确率的提升只有一部分能转化成下游任务收益，说明"用好技能"本身成了瓶颈，而且检索目标和实际解题需求对不上。
- **生成式技能检索**：模型不再拿原始问题直接去匹配技能库，而是在推理中途生成"我需要什么技能"的描述，交给外部检索引擎（BM25、稠密检索等均可）取回技能，再接着推理使用。
- **两阶段训练**：先用强教师模型产出的高质量轨迹做 SFT 预热，让模型学会这种交互格式；再用 GRPO 以任务结果为奖励，把奖励回传到整条轨迹，同时优化检索决策和技能使用。
- **Token masking**：检索回来的技能文本不计入损失，只训练模型自己生成的检索请求和推理内容，保证训练稳定。

## 关键结果

- 在 SRA-bench 的 5 个技能相关基准上，任务完成率和技能检索效果都达到 SOTA。
- 相比基座模型，Qwen3-4B 平均提升 66.59%，LLaMA3.1-8B 平均提升 34.82%。
- 可适配多种检索引擎，泛化性和鲁棒性较好。

## 为什么值得关注

Agent Skills（如 Claude Skills）正在成为 Agent 扩展能力的主流方式，技能库越大，"找得到"和"用得好"越成为瓶颈。这篇工作把 Search-R1 一类"模型自主检索 + 结果奖励 RL"的思路迁移到技能场景，证明了检索要以下游效果为目标来端到端优化，而不是单独刷检索指标。小模型也能用上，对搭建技能型 Agent 的工程团队有直接参考价值。

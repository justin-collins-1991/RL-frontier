## 一句话概括

把双模拟度量（衡量两个状态"对任务而言有多像"）重新解释为一个零和回合制博弈的值函数，使它在无折扣（总奖励、平均奖励）设定下也有唯一、可分析的定义。

## 核心方法

以往的双模拟度量都是"某个算子的不动点"，靠折扣因子 γ<1 的压缩性保证唯一；γ=1 时不动点可能有无穷多个。作者发现这些算子其实就是某个两人零和博弈的 Bellman 算子：一方挑动作拉大两状态的差异，另一方挑转移耦合缩小差异。于是直接把度量定义为博弈的最优值，γ=1 时依然唯一，还能直接复用现成的博弈/动态规划理论和求解算法。在此基础上，作者分析了度量何时有限（与 MDP 的连通结构相关），提出在弱连通 MDP 中仍保持有限的"有向"度量，并给出一个可替换耦合集合的抽象框架，统一涵盖多种已有度量。

## 关键结果

- 证明这些度量能上界总奖励最优值之差，以及最优增益与状态无关时的相对价值差；
- 给出总奖励、平均奖励设定下基于状态聚合做规划的误差与次优性保证；
- 原始 bisimulation、lax 等经典度量都可作为框架的特例导出。

## 为什么值得关注

目标到达、最短路径、长期持续控制等任务天然是无折扣的，而状态表征学习的理论此前基本只覆盖折扣情形。这篇工作补上了理论基础，也为在平均奖励 RL 中做状态抽象、表征学习提供了有保证的设计思路。

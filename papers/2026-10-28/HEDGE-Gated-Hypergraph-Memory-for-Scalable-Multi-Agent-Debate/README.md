## 一句话概括

HEDGE 把多智能体辩论的过程组织成一张共享的"语义超图"记忆，再用一个经 RL 训练的门控模块决定每条信息存、备份还是丢，让辩论更准确，也更省资源。

## 核心方法

- **两层结构化记忆**：辩论中抽取出来的原子论点作为节点，语义相近的论点（可以来自不同智能体）聚进同一个超边，用来表达"多方一致""证据冲突"这类多元关系。每个超边内部再维护一张有向关系图，记录支持、反驳、证据、依赖、推导等细粒度关系。
- **学习式记忆选择模块（MSM）**：把候选信息和当前各超边的中心做交叉注意力，再分类为 STORE / BACKUP / OMIT。先用监督学习预训练，再用辩论结果当奖励做强化学习微调，按信息"随辩论演化的实际价值"来取舍。
- **辩论内读写**：所有智能体每一轮都能检索、更新这份记忆，避免重复讨论已经被否掉的假设。

## 关键结果

- 在 7 个基准（数学推理、知识冲突、长上下文问答）上全面超过单智能体、多智能体和记忆类基线。以 GPT-4o-mini 为骨干时，比最强多智能体系统平均高 5.0 个点，在冲突较多的任务（如 ConflictQA）上高 8.2 个点。
- 记忆占用减少 48%，辩论轮数减少 34%。

## 为什么值得关注

多智能体辩论的瓶颈正在从"多几个 agent"变成"长历史怎么管"。HEDGE 说明结构化记忆加上 RL 学出来的取舍策略，可以同时提升准确率和效率。"拿下游任务结果当奖励来训练记忆管理"这个思路，也可以迁移到长程 agent 和多 agent 协作系统里。

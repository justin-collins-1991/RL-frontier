## 一句话概括

RAMA 让低轨卫星网络里的每颗卫星都维护一份自己的"路由经验库"，做转发决策时检索相似的历史经验来参考，从而在分布式多智能体强化学习路由中明显降低时延，尤其是尾部时延。

## 核心方法

- **每星一份情景记忆**：每颗卫星记录自己过去的转发决策，并在包送达后补上真实的端到端结果。决策时按当前观测检索最相似的 8 条经验。
- **Transformer 融合多源信息**：把当前观测、最近 8 次路由历史、4 个邻居状态和 8 条检索到的记忆分别编码成 token，用 Transformer 统一处理后输出下一跳。记忆不直接用来估值，而是作为决策网络的输入上下文。
- **AIS 辅助训练目标**：引入近似信息状态（AIS）框架的辅助损失，让学到的表示同时包含与奖励相关和与网络动态相关的信息。
- **部署后记忆持续生效**：模型权重冻结后，记忆库仍会不断写入、检索新经验，不重新训练也能跟着网络变化做调整。

## 关键结果

- 140 颗卫星的 Kepler 星座、权重冻结：相比 SOTA 的 DDQN 路由，平均端到端时延降低 13.4%，P99 时延降低 66.7%，收益主要来自避开了长距离绕路。
- 在线更新时，RAMA 保持稳定，DDQN 性能反而下降。
- 在 1584 颗卫星的 Starlink shell 1 上，平均时延降低 93.2%；在线更新后平均时延还能再降 25.5%。

## 为什么值得关注

低轨星座的轨道和流量都有很强的周期性，相似场景会反复出现，"查以前怎么走的"比单靠网络权重记住经验更直接。RAMA 把检索增强（RAG 思路）带进去中心化的多智能体 RL 路由，星座规模越大优势越明显，而且权重冻结后仍能靠记忆适应变化，便于在星上部署。这一思路也可以推广到其他周期性强、只能看到局部信息的网络控制问题。

## 一句话概括

长程 LLM 智能体靠"递归改写的文本记忆"记事，但旧错误会被一轮轮沿用下去。KEEPER 在同一套记忆接口下比较了四种辅助训练目标，看哪种监督信号对智能体最有用。

## 核心方法

记忆生成器每一步根据"上一版记忆 + 上一步动作 + 当前观测"重写记忆。作者把上一版记忆里已有的错误在后续更新中持续存在称为**自一致性偏差**：比如记忆错写成"前置步骤已完成"，后面就一直照抄。KEEPER 从两个角度设计辅助目标：
- **信息内容**：奖励预测（RP）、后继上下文预测（PP）、与参考记忆语义对齐（SA）；
- **更新敏感性**：更新稳定性（US），惩罚记忆生成器对输入记忆扰动过于敏感。

先用行为克隆配合辅助目标做初始化，再做离线强化学习，推理时辅助目标都不参与。

## 关键结果

- 在 ScienceWorld 和 ALFWorld 上，无论离线 RL 之前还是之后，单用奖励预测（RP）的任务表现都最好；
- 四个目标一起用反而不如单用 RP，说明各目标的收益加不起来；
- 作者对一条基线轨迹做了逐条论断分析：即使后来出现了纠正性的观测，错误论断仍会延续，或者纠正后又重新出现。

## 为什么值得关注

做 Agent 记忆的人通常只看任务成功率。这篇提醒我们：成功率高不代表记忆可靠，评估时还应直接衡量错误延续了多久、正确信息保住了多少。另外，"奖励相关预测"是一个简单有效的辅助信号，"多个目标叠加更好"这种直觉在这里并不成立。

## 一句话概括

ERIM 让多模态大模型做上下文学习时，先从示例中显式归纳出隐藏规则，再把规则用到新问题上，而不是直接模仿输入到输出的映射。

## 核心方法

- 聚焦 "Case II" 任务：单看问题本身无法作答，答案取决于示例之间共享的规则。
- 规则中心的数据构建：从 VQA 数据集和合成数据中按规则分组，采样"支持集 + 查询"组成 episode；把图像转写成保留规则信息的文字描述，交给推理型 LLM 生成"先归纳规则、再作答"的思维链，并用 LLM 评审筛掉不忠实的推理链，作为显式的规则归纳监督。
- 两阶段训练：先用多模态 episode、纯文本 ICL episode 和只带答案的样本混合做冷启动 SFT，教会模型 think-then-answer 的格式；再用 DAPO 强化学习，以格式和答案正确性作为奖励，进一步强化规则推理。

## 关键结果

在多种 Case II 多模态上下文学习基准上，相对强基线取得一致提升。分析显示，规则归纳得越准，最终答案越准、越稳定，归纳出的规则也能跨上下文迁移。

## 为什么值得关注

它把多模态上下文学习从"模式模仿"推向"显式归纳推理"，输出的规则本身也带来了可解释性。"文本代理生成推理监督 + 冷启动 SFT + RL"这套配方，对其他需要从少量示例中抽象规律的多模态任务也有参考价值。

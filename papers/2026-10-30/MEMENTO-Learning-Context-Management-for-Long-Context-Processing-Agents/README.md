## 一句话概括

先用 SFT 教会 Qwen3-8B 智能体“记笔记”，再用 RL 打磨笔记质量。这样它只用不超过 20K 的上下文窗口，就能对最长 2.5M token 的整本书做多跳问答。

## 核心方法

- **问题**：智能体处理长输入时，历史记录会越积越多，窗口迟早被撑满。常见做法是“压缩”：用一份自己写的笔记替换掉历史记录。但 GPT-5.5、GLM-5.3 这类现成模型几乎写不出有效笔记，单靠 RL 也很难自己摸索出来。
- **SFT 冷启动**：收集 GLM-5.3 答对的轨迹，事后往里插入笔记（记录已找到的证据、走过的弯路和下一步计划），用这些合成数据微调 8B 模型。
- **RL 强化**：用 GRPO 训练，奖励由四部分组成：答案正确性、笔记质量启发式规则、格式合规、置信度校准。同一条轨迹跨多个窗口时共享同一个优势值。
- **测试时灵活扩展**：训练时只用“压缩后开新窗口”这一种方式。由于笔记格式是统一的，推理时可以直接改用“上下文折叠”（保留笔记和最近几轮），或在置信度低时回退到更早的笔记检查点重新探索。

## 关键结果

- 在 4 个书籍问答基准上（其中 NovelQA 未参与训练），准确率从 36.9% 提升到 67.8%。
- 同一套框架下，GPT-5.5 智能体只有 13.1%；GPT-5.5 读全书为 56.7%，成本却是 MEMENTO 的 50 多倍。
- 与约 100 倍规模的 GLM-5.3 智能体（69.3%）几乎持平，成本只有其 1/9；比 GLM-5.3 读全书低 6.4 个百分点，成本只有 1/26。

## 为什么值得关注

论文说明“管理上下文”是一种可以学出来的能力，而且小模型配合训练好的记笔记策略，就能在长文本任务上逼近甚至超过大模型读全文的效果，成本低一到两个数量级。论文给出了一套可复用的做法：用事后插入笔记的数据冷启动，再用过程奖励加结果奖励做 RL，并在训练和推理框架上协同设计。其中的置信度回退机制，也为长任务智能体何时该花更多算力提供了一个实用信号。

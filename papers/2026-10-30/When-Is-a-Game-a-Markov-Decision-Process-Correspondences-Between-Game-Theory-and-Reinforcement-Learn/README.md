## 一句话概括

这是一本参考手册式的专著。它把博弈论和强化学习中“名字不同、结构相同”的概念逐一对应起来，并且说明每条对应在什么条件下成立，什么条件下不成立。

## 核心方法

作者把“博弈是不是 MDP”分成三种强度：
- **定义等同**：本来就是同一个模型，只是名字不同，比如共同收益的 POSG 和 Dec-POMDP。
- **精确归约**：有定理保证映射前后的价值和解集都不变，比如 Dec-POMDP 可以转成占用状态上的 MDP。
- **结构类比**：形式相似，但在可以指出的条件下会失效，比如“把其他智能体当作环境的一部分”。

正向部分，作者覆盖了标准形、重复、随机、部分可观测、扩展式、贝叶斯、Stackelberg、势博弈、合作博弈、平均场、演化博弈等十余类博弈，为每类找到 RL 中对应的模型，并给出只有一个智能体时退化成什么。解概念也做了同样的对应，例如纳什均衡对应 Bellman 不动点，QRE 对应 soft Bellman，Shapley 值对应信用分配。作者还把每类模型和适用的训练算法、问题复杂度一一对应，并严格区分“规划”（模型已知）和“学习”（模型未知）两种场景。

## 关键结果

- 给出成体系的对照表，每一条都标明属于三种强度中的哪一种。示例中的数字都由配套程序重新计算过。
- 专门整理了不成立的对应关系：
  - 对手也在学习时，环境不再平稳，独立学习者的归约随之失效；
  - 不可能定理表明，非耦合（uncoupled）动态无法保证收敛到纳什均衡；
  - no-regret 自博弈只能保证到达粗相关均衡（CCE），并不是常被宣称的相关均衡（CE）；
  - 带噪声的独立学习倾向于选中风险占优均衡，而不是收益占优均衡；
  - 共同收益博弈中，集中式规划和分散式执行之间存在均衡选择的鸿沟。

## 为什么值得关注

MARL 实践中常把单智能体算法直接用到多智能体问题上，背后的理由往往只是“类比”，却被当成定理来用。这份词典能帮工程师判断：某个归约到底是严格成立，还是只是看起来像；选什么算法才可靠；自博弈实际收敛到的是什么均衡。它适合作为多智能体 RL 研究的常备参考。

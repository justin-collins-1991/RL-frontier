## 一句话概括

用一个 Transformer + PPO 训练出的通用策略，在剂量档数不同的一期临床试验中决定"降、留、升"剂量，最终 MTD 则交给透明的统计规则来选。

## 核心方法

- **剂量即 token**：每个剂量档编码为一个 token（归一化位置、已入组人数、观察到的剂量限制性毒性 DLT 数、是否当前剂量），因此 4~10 档剂量都能用同一个模型处理。
- **试验条件化的交叉注意力**：用目标毒性率、样本上限、已入组人数等试验上下文作为 query，对编码后的剂量 token 做注意力汇聚，得到固定维度的表示，再接三动作策略头（降/留/升）；在最低剂量选"降"就等于提前安全终止。
- **分配与决策解耦**：RL 只负责每批病人用什么剂量；样本用满后，由加权保序回归加安全上限选出最接近目标毒性的剂量，不让奖励函数隐式决定最终推荐。
- 奖励 = 终局推荐对错（±1）减去每例 DLT 的惩罚 λ。

## 关键结果

- 带毒性惩罚（λ=0.05）的策略明显降低了患者的 DLT 负担；不加惩罚的策略 MTD 选择准确率更高，但毒性也更多。
- 通过 λ 可以显式调节"安全—准确"的权衡。
- 作者坦言：结果不能证明优于 BOIN、CRM 等传统设计；PCS 约 0.10 的提升主要来自最终选择规则的平局处理改进，而不是 RL 策略本身。

## 为什么值得关注

这是把 RL 应用到高风险医疗决策时比较克制的一种范式：用 token 化表示解决变长剂量网格的泛化问题，把可学习的部分限定在序贯分配上，最终临床推荐保持可解释、可单独评估。论文对自身局限的坦诚也值得参考，适合作为"RL + 临床试验设计"的基线框架。

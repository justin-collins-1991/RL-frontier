## 一句话概括

LLM 遗忘真正该删的不是整段回答，而是"问题 → 关键答案"之间的知识关联（KA）。论文基于这一点提出强化学习遗忘框架 KARU，做到更精准地遗忘、更少地误伤。

## 核心方法

作者观察到，模型完成遗忘后，预测分布的变化几乎都集中在"知识 token"上（如"Stephen King 的第一部小说是 Carrie"里的 Carrie），其余语言性 token 基本不变。因此他们把遗忘目标定义为知识 token 位置上的条件预测分布，并在 RL 框架里用三个互补的组件来优化它：

- **知识关联 token 奖励（KATR）**：从目标的梯度分析推出 token 级奖励，把优化信号集中到承载知识的 token 上，不再像序列级奖励那样所有 token 一视同仁。
- **Logits 平坦化（LF）**：把知识位置上的分布压平，不只是压低正确答案的概率，从而避免知识残留在分布里、之后被重新提取出来。
- **自适应邻域采样（ANS）**：误伤通常发生在与遗忘目标相近的知识上，所以保留集训练时优先采样这些更容易受损的"邻居"样本。

## 关键结果

作者在多个 LLM 基座、多种 RL 算法和代表性遗忘基准上做了实验。KARU 的遗忘效果稳定优于现有基线，综合遗忘分数比 SOTA 最多高 30.5%，保留集表现和通用能力与基线相当。消融实验表明三个组件各自都有贡献。

## 为什么值得关注

这项工作把"该忘什么"从整段回答细化到知识 token 及其分布，并且不需要人工标注敏感片段，就能为 RL 遗忘提供细粒度的信号。它还把"误伤具有局部性"这个现象变成了可以利用的采样策略。对于需要满足 GDPR"被遗忘权"、删除隐私或版权内容的场景，这种思路很实用，也给 RL 中 token 级的信用分配提供了一个具体案例。

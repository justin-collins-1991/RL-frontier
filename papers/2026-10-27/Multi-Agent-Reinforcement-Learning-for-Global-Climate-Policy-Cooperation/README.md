## 一句话概括

在已有的 MARL 气候政策环境中加入“提议—接受—履约”三阶段谈判机制，用来实验不同协议设计对减排合作的影响。结果发现，违约惩罚要适中：太轻挡不住搭便车，太重则没人敢做出有力度的承诺。

## 核心方法

- 底座沿用 Lassen 等人的环境：每个智能体代表一个国家，每年选择三类减排力度和预防性投资。全球温升由 CICERO-SCM 的神经网络代理模型算出，奖励等于负的（气候损失 + 政策成本）。
- 每个政策年拆成三个阶段：先提出双边协议（我承诺多少、要求对方多少），再决定接受或拒绝，最后执行实际的气候行动。谈判阶段本身没有奖励，影响只体现在执行阶段。
- 已接受的承诺如果没有兑现，就会被罚一笔固定的违约成本（目前只针对甲烷减排这一项）。惩罚为 0 时就是不具约束力的协议。
- 每个智能体用独立的 LSTM actor-critic 和 PPO 训练。实验设置为 4 个同质智能体，并与“全体等力度减排”和“单方背离”两个固定策略对比。

## 关键结果

- 协议不具约束力时，学到的策略整体不如等力度基线，各方减排分布也不均衡。单方背离测试证实，少减排的一方收益更高，搭便车的动机始终存在。
- 低惩罚时集体奖励就能超过等力度基线，峰值温升也明显下降，但仍有 5–15 次违约。
- 中等惩罚下违约降为零，奖励保持在相近水平，接受的承诺力度最高可达 0.83。
- 高惩罚时，智能体不再接受高力度的承诺（最高只有 0.32），集体奖励反而下降，体现了“执行力度与参与度”之间的权衡。

## 为什么值得关注

这项工作首次把谈判机制和较精细的排放—温升响应放进同一个 MARL 环境，让“协议怎么设计”变成可以跑实验检验的问题。它提供的是方法论层面的实验台，不用于预测真实谈判。局限也很明显：只有 4 个同质智能体、只做了 3 次运行，扩展到异质国家后结论是否还成立有待验证。对多智能体合作、机制设计方向的研究者有参考价值。

## 一句话概括

NEXUS 是一个分层强化学习框架：用符号规则在高层决定“做什么”，用神经网络技能在底层决定“怎么做”，让智能体可解释，性能也不打折。

## 核心方法

- **把解释放到技能层**：直接对按键级动作写符号规则会让规则数量爆炸、根本读不懂。NEXUS 把动作抽象成“战斗 / 救人 / 上浮”这类技能，规则只负责选技能，所以很短、好读。
- **以物体为中心的输入 + LLM 辅助**：先从画面里提取物体状态，再让 LLM 生成每个技能的奖励函数和高层规则，减少人工设计。每个技能有自己明确的子目标，因此技能之间互不纠缠。
- **分层 PQN 联合训练**：把并行 Q 网络（PQN）扩展到分层场景，元策略和各技能各自学一个 Q 函数，用同一批经验离策略地一起训练。
- **三种元策略对比**：纯神经（最灵活）、纯符号（最透明）、神经符号混合（先用规则筛掉不相关的技能，剩下的再交给 Q 值选）。

## 关键结果

在 Atari 等游戏上，NEXUS 的回报和深度 RL 相当；学到的技能语义清楚、互不干扰，高层决策能看懂；行为更符合游戏手册里写的目标，更不容易钻奖励的空子，游戏被简化后也更稳健。论文还单独比较了三种元策略在环境回报和对齐任务表现上的取舍。

## 为什么值得关注

它给出了一条可解释 RL 的实用路线：不要求整个策略都透明，只要求高层决策透明。再加上 LLM 来降低规则和奖励的设计成本，对需要审计、对齐和排查奖励钻空子的场景很有参考价值。

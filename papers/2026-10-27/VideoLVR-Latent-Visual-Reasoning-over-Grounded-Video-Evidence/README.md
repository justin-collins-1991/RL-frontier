## 一句话概括

让视频大模型在思维链中插入“隐式视觉证据”，不必重新塞入帧或裁剪图，就能在推理中回看关键画面，缓解视觉遗忘。

## 核心方法

- **证据化轨迹数据**：用教师模型生成带“时间戳 + 框”的推理轨迹，经拒绝采样和润色后，把同一推理步骤用到的跨时刻局部区域按时间排序，组成一个隐式证据块的监督目标。
- **视觉 token 预测（VTP）**：不用 MSE 回归特征，而是把输入视频的全部视觉 token 当作“词表”，让模型从中挑出目标 token，和文本的下一词预测统一在同一框架里，能更好地区分相邻帧里相似的画面。
- **推理时**：解码器隐状态被投影成隐式视觉状态并回填给模型，上下文几乎不增长。
- **TVPO 强化学习**：把采样出的视觉 token 和文本 token 一起当作动作，只用最终答案奖励联合优化策略。

## 关键结果

在多个视频理解与推理基准上带来提升，在需要细粒度视觉证据的任务上增益最明显；消融实验验证了证据分组、VTP 和 TVPO 各自的作用。

## 为什么值得关注

它在“文本坐标（省 token 但丢失画面内容）”和“工具裁剪回填（保留细节但上下文膨胀）”之间找到了折中。更重要的是，它把 RL 的动作空间从文本扩展到视觉 token，为多模态隐式推理的强化学习提供了一条可行思路。

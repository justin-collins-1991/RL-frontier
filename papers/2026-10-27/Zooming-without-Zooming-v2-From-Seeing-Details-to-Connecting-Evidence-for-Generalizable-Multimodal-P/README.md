## 一句话概括

空间感知、多模态长上下文这类任务的训练数据很难造。作者发现它们底层都依赖同一种能力，叫“串联证据”：找到相关的视觉事实，把事实对应到正确的对象上，再理清它们之间的关系，最后拼出答案。针对这种能力的数据容易合成得多，作者用单张图片合成训练数据，再用 RLVR 训练，得到 ZwZ2。

## 核心方法

- **EvidenceConnect 数据合成**：在一张高分辨率复杂图片里挑出几个相关区域，用这些区域的放大裁剪图生成需要比较、汇总或链式推理的问题。例如：登机牌上的航班号 → 对应登机口 → 该登机口的服务图标。放大图只在造数据时使用。
- **质量把关**：一是让不同家族的 VLM 分别作答，答案一致才保留；二是做区域消融测试，逐个遮掉选中的区域，如果遮掉后答案仍然能推出来，说明题目不依赖这些证据，直接丢弃。
- **训练**：通过质量把关的题目会转成选择题，方便按规则给奖励，再做难度过滤。训练时模型只看到完整原图，选中区域用彩色框标出。以 Qwen3.5-4B/9B 和 Qwen3.6-27B 为基座，不做 SFT，直接跑 RLVR。

## 关键结果

- 25 个基准的平均分：4B 从 49.41 提到 54.79，9B 从 51.63 提到 56.59，27B 从 55.52 提到 60.51。
- ZwZ2-4B 在 ViewSpatial-Bench 上提升 7.83 分，在 MileBench（长上下文）上提升 10 分。
- 训练只用了单图数据，但在多图长上下文、具身空间推理、多模态 Agent 和通用视觉推理上也都有提升。

## 为什么值得关注

具身和 Agent 场景的数据很难直接合成。这篇工作的思路是先找出这些任务共用的底层能力，再为它造便宜、可验证的替代任务，结果显示这种训练能迁移到更广的任务上。跨模型答案一致性校验和区域消融两步过滤简单好实现，适合直接拿来做多模态 RL 的数据生产管线。

## 一句话概括

RePPO 把 PPO 改成同时训练一小群策略。每个策略的奖励里加了一项“离其他策略远一点”的互斥信号，不用进化算法也能得到既强又多样的策略群。

## 核心方法

- **目标来自 Soft QD**：策略群的总分等于各策略的任务表现之和，再减去“两个都很强、行为又很像”的策略对的重叠惩罚。
- **关键推导**：如果行为描述可以写成每一步信号的累积（比如步态、速度方向），那么每个策略对这个总分的梯度，正好等于在一个“塑形奖励”下的普通策略梯度。这个奖励由任务奖励加上一项随当前策略群变化、把自己推离相近高分同伴的行为项组成。
- **工程落地**：直接套用 PPO 训练，并加入若干稳定性控制，平衡个体质量和群体多样性。整个过程不需要 MAP-Elites 那种行为网格存档，也不需要变异、交叉等进化操作。

## 关键结果

- 在标准连续控制任务上，质量和多样性的折中表现与现有最强 QD-RL 方法相当或更好。消融实验分析了各组件对质量和多样性的影响。
- 在 Atari 像素任务上，策略网络太大，传统 QD-RL 基本跑不动。RePPO 的得分与普通 PPO 持平，多样性明显更高。
- 在数学推理的 zero-RL 大模型微调中，首次证明 QD-RL 能扩展到 LLM 场景。

## 为什么值得关注

以往 QD-RL 依赖存档和进化搜索，策略一大、行为维度一多就扩展不动。RePPO 把“多样性”变成奖励里的一项，用标准 PPO 就能训练，可以直接接入现有 RL 基础设施，包括 LLM 的 RL 微调。它为获得多种解题风格、提升探索覆盖提供了一条实用路线。

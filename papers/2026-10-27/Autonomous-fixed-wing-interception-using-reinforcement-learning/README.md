## 一句话概括

用 PPO 训练一个神经网络策略，把滤波后的单目视觉观测直接映射成舵面/油门指令，让低成本固定翼无人机自主拦截目标，并在真实飞行中验证成功。

## 核心方法

- **问题背景**：Shahed 类中高空长航时无人机难以低成本防御；四旋翼拦截机航时太短，固定翼航程够但目前仍靠人工操控。
- **端到端控制**：策略输入是经过滤波的单目相机观测（目标在画面中的信息），输出直接是执行器指令，省去传统"制导律 + 姿态控制"的分层设计。
- **训练**：在自研 Python 仿真环境中用 PPO 训练，然后直接部署到真实固定翼平台。
- **对照组**：另外实现了两种经典制导控制器，在仿真中作为基线对比。

## 关键结果

- 仿真中，RL 策略在大多数条件下优于两种经典制导控制器。
- 策略可从仿真迁移到实机，在真实飞行中成功拦截了做机动的固定翼目标。
（基于摘要）

## 为什么值得关注

这是 RL 端到端控制在高动态固定翼拦截任务上的一次实机闭环验证：仅靠廉价单目相机、无需昂贵导引头，就实现了 sim-to-real 迁移，且性能超过经典制导基线。对做无人机控制、视觉伺服和 sim-to-real 的工程师来说，它提供了一个"轻量自研仿真 + PPO + 直接部署"的可行范式；同时也说明了学习型控制器在低成本反无人机防御中的应用潜力。

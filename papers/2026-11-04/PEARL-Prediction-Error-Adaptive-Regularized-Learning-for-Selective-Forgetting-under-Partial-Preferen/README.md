## 一句话概括

用户偏好往往只变一部分。PEARL 让神经上下文老虎机只在“预测明显出错”的特征方向上重新变得不确定，其余方向的置信度原样保留，从而做到选择性遗忘。

## 核心方法

- **双向 Gram 更新**：NeuralUCB 的 Gram 矩阵只会越来越自信，学过的方向从此几乎不再探索。PEARL 在某次预测误差超过该用户的历史平均水平时，沿这次交互的特征方向把不确定性“加回去”，并设上限防止失控。注入率设为 0 就退化成标准 NeuralUCB。
- **误差自适应探索**：为每个用户维护一个预测误差的滑动平均，用它去缩放 UCB 探索奖励。预测得准的用户基本走贪心，预测失准的用户加大探索。偏好稳定时两个机制都会自动“休眠”。
- 理论上证明：不做自适应的策略在偏好变化后必然产生线性遗憾；任何固定探索率都无法同时兼顾稳定和漂移两种情形；PEARL 的累计遗憾随“发生变化的用户数”增长，而不是随总用户数增长。

## 关键结果

- 在 PRISM 上（1,500 用户、21 个 LLM 的个性化回复选择，中等程度漂移）：比贪心高 4.0 个点，比最好的神经老虎机基线高 2.5 个点（p<0.001）；偏好稳定时与贪心持平。
- 比滑动窗口、折扣 Gram 这类“统一遗忘”方法高 3~10 个点。不做在线更新的静态模型甚至不如随机选择。

## 为什么值得关注

它把“局部漂移”明确提出来作为一个独立问题，并给出了一个便宜、可插拔的解法：策略只是一个约 10 万参数的 MLP，在 CPU 上毫秒级运行，不改动 LLM 权重，可直接配合纯 API 调用的模型使用。对个性化推荐、奖励模型在线校准这类场景来说，工程上很容易落地。

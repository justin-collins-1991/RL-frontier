## 一句话概括

MAC-v2 把基于模型的长时域价值扩展从低维状态推广到图像输入，在像素级离线 RL 中实现了超过 100 步的稳定想象推演。

## 核心方法

- **免重建隐空间世界模型**：编码器不还原图像，而是由动力学预测、奖励预测和行为克隆共同训练，只保留与控制相关且容易预测的信息。
- **动作分块**：策略和世界模型一次处理 n 步动作，想象 H×n 步只需递归预测 H 次，误差累积大幅减少。
- 沿用 MAC 的 flow matching 策略和拒绝采样，让策略尽量停留在数据分布内，再用模型内的长时域推演来估计价值。

## 关键结果

- 25 个视觉 OGBench 任务上明显超过无模型和有模型基线；在 MMBench2 上与最强方法持平。
- Robomimic 上是唯一在所有任务都不低于行为克隆的 RL 方法；LIBERO-10 上与强行为基线相当。
- 消融显示：长时域价值扩展是性能的关键，动作分块和隐空间学习目标缺一不可。

## 为什么值得关注

以往的像素级离线有模型方法一般只想象 5 步左右。本文说明，只要表征设计得当、递归预测次数足够少，视觉任务上的长时域想象同样可靠。这为直接从相机画面学习机器人策略提供了一条可扩展的路线，减少对短视的离策略自举的依赖。

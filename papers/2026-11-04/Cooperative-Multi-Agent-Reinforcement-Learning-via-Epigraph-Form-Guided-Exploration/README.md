## 一句话概括

EFXPLORER 把多智能体探索改写成“在不降低团队任务表现的前提下尽量多探索”的约束优化问题，用上镜图（epigraph）形式求解，避免了内在奖励把任务目标带偏。

## 核心方法

- **不再加权混合奖励**：常规做法是“外部奖励 + β×内在奖励”，β 难调，且一个智能体乱探索会让队友误以为合作失败，导致协作崩溃。本文把内在奖励和任务目标分开处理。
- **探索预算 + min 门控**：为每个智能体引入一个可自适应的“探索预算”。策略更新时取“任务进步（外部优势）”与“超出预算的探索收益”两者的较小值，任务信号不足时自动抑制探索。
- **交替优化**：内层在固定预算下更新策略，外层根据近期高新颖度轨迹、在任务表现不退化的前提下逐步抬高预算，让探索边界稳步外扩。
- **后继距离内在奖励**：在每个智能体自己的状态空间上估计 successor distance，奖励“时间上远”的新状态，能捕捉长程结构，又绕开联合状态空间的维度爆炸。

## 关键结果

在 SMAX、VMAS、MPE 三套基准上稳定超过强基线，并在协作搬运等任务中涌现出新的合作策略；相比线性加权的内在奖励方法，不会出现探索导致协作崩溃的问题。

## 为什么值得关注

“探索与任务目标打架”是 MARL 的老问题，本文给出了一个几乎不需要调权重系数的通用解法：探索只在任务不受损时放行。这种“约束式保守探索”思路可以直接迁移到其他需要内在奖励的 RL 场景（如稀疏奖励、单智能体探索），对实际工程调参很友好。

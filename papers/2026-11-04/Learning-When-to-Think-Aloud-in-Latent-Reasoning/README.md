## 一句话概括

VITAL 让模型在隐式推理中学会“何时说出来”：只显式生成少量关键 token 作为锚点，其余计算都在隐藏状态里完成，兼顾准确率和推理长度。

## 核心方法

- **门控头**：在模型上加一个轻量门控，每一步决定是正常解码一个 token，还是直接把当前隐藏状态回喂给下一步做隐式计算。
- **构造混合轨迹**：用 LLMLingua-2 给显式 CoT 打重要性分，在**每个推理步骤内**保留得分最高的一部分 token（如数字、运算符）作为锚点，其余连续片段压缩成固定数量的 `<latent>` 占位。
- **两阶段训练**：先用课程式 SFT 逐步把显式 CoT 换成混合轨迹，再用 RL 后训练，奖励同时考虑答案正确性和推理简洁性。

## 关键结果

- 推理长度相近时，比纯隐式推理方法平均准确率相对提升 9.6%（GPT-2）和 5.1%（Llama-3.2-1B）。
- 在 Qwen3-1.7B 上，与 Token Assorted、HRPO 等混合方法相比，准确率更高，推理轨迹明显更短。
- 消融实验表明：选高重要性 token 做锚点，效果优于随机选或选低重要性 token。

## 为什么值得关注

纯隐式推理在数学这类对精度要求高的任务上容易丢失中间数值，现有混合方法又省不了多少 token。VITAL 的思路很直接：只把关键中间结果“说出口”当锚点，在准确率和长度之间找到了更好的平衡。它还用 RL 进一步压缩推理长度，为“高效推理 + RL 后训练”提供了一个可落地的方案。不过实验目前只在 2B 以下的小模型上做，能否推广到更大模型还有待验证。

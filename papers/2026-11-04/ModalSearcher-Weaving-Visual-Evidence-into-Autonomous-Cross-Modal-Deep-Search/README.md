## 一句话概括

训练多模态搜索智能体，在多跳推理中自己决定用文搜文、文搜图还是以图搜图，并把文字证据和图片证据串起来回答问题。

## 核心方法

- **问题定义**：现有方法要么只在开头看一眼输入图片，之后全在文本里搜；要么题目里直接指定“去搜某张图”。作者把真正需要的能力称为“自主跨模态搜索”：每一步由智能体根据当前缺什么信息，自己选择直接推理、文搜文、文搜图或以图搜图。
- **数据管线（ModalSearch-Pipeline）**：先构建图文交错的知识图谱。图片节点只保留能被稳定检索到的，图中实体经过校验后再链接回文本。然后在图上采样深度和模态组合各不相同的路径，再倒推出问题：隐去会让模型走捷径的实体名和目标图片，保留消歧所需的线索，也不在题目里提示“该切换模态了”。
- **训练**：先用 SFT 教会 ReAct 式工具调用，再在真实网络环境中做强化学习，优化多轮搜索决策。

## 关键结果

- 在相同智能体流程下，ModalSearcher-8B 在 5 个多模态知识密集型问答基准上平均 57.0 分，比 Qwen3-VL-8B 高 16.2 分。
- 在第三方构建的主动视觉搜索基准上，VisBrowse 提升 19.8 分，BrowseComp-V3 提升 15.8 分，说明收益不只来自与训练数据同源的题目。
- 消融实验表明，图文交错路径、多模态工具和 RL 阶段都对提升有贡献。

## 为什么值得关注

多模态深度搜索正从“看图再搜文本”走向“边推理边按需搜图”。这篇论文给出了一套可扩展的数据合成方法，能自动造出带隐式视觉依赖的多跳题目，再配合真实网络环境中的 RL，让 8B 小模型学会切换模态。对做多模态智能体或搜索类 RL 的团队来说，这套数据构造思路可以直接参考。

## 一句话概括

用 Qwen3.5-9B 玩吃豆人，把“看懂画面”和“选对动作”分开排查，总结出智能体 RL 后训练在评估上最容易踩的几个坑。

## 核心方法

- **拆分问题**：感知和决策分开测。感知方面，单独检查模型从截图里读棋盘和角色位置的准确度；决策方面，直接把棋盘以 ASCII 文本喂给策略，跳过图像识别，只考察上下左右怎么选。
- **策略 RL**：PPO 风格的裁剪目标，配合七阶段课程学习（迷宫、目标、鬼的数量逐步变化），保留约 19% 的早期阶段复习；另外用“回放/从死前状态重启”来增加难点状态的训练量。
- **评估纪律**：严格区分正常开局的验证和重启训练时的胜率；不只看挑出来的最佳 checkpoint，还要看完整曲线和后续表现。

## 关键结果

- 8 个留出迷宫上（3 条额外命），通关率从训练前的 0/96 提升到选定 checkpoint 的 77/96（80.2%）；但峰值 78/96 之后，最后一次验证掉到了 60/96。
- 静态截图读得准，交互过程中照样会读错。
- 在另一条训练线上，继续优化反而让验证通关数下降，回放中还出现了直接送命的动作。

## 为什么值得关注

这篇论文的贡献在经验层面，而不是新算法，但对做智能体 RL 的工程师很实用：只盯一个最高分或训练胜率容易高估效果。感知要放在实际交互中测，训练成功要和完整对局的验证分开看，还要逐个检查具体决策和后续表现，这样才能判断问题出在“看”还是“做”。

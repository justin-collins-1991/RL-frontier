## 一句话概括

只看回放池里的数据本身，给每条经验打一个“有多反常”的分数，让稀有的边界情况被更多地采样，从而缓解机器人 RL 中常规样本占满回放池的问题。

## 核心方法

- 用统计杠杆分数（相当于样本偏离整体分布的程度）给每条 transition 打分，不依赖奖励、标签或 critic，计算开销低，适合整池刷新。
- mini-batch 从“杠杆分数采样 + 均匀采样”的混合分布中抽取。
- 三个关键改进：动作用 one-hot 编码时，按方差选主方向会失效，因此改为挑尾部最重（峰度最大）的特征列打分；去掉 PER 式重要性权重修正，因为完全修正后效果恰好退化成均匀采样；稀有情况如果体现在“行为与目标的关系”上，就对相对目标描述的短轨迹窗口打分。

## 关键结果

在三关节机械臂绕障推物任务上（TD3+BC），稀有任务成功率从 0.49 提升到 0.69，接近使用标签的 oracle 上限 0.74。论文还在高斯混合模型上给出了精确的采样占比规律，并在网格世界离线 Q 学习中验证了数据稀疏区域学得更好。

## 为什么值得关注

连续控制领域默认仍用均匀回放，PER 的效果时好时坏。本文提供了一个与 critic 无关、几乎即插即用的多样性采样信号，还指出了 one-hot 导致失效、重要性修正把效果抵消掉这两个容易踩的坑，对真机等数据昂贵的场景有直接参考价值。

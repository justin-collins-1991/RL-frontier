## 一句话概括

Amazon 用"可验证奖励强化学习（RLVR）"微调开源文生图模型，专治线稿图标在小屏粗线条下"笔画挤成一团"的缺陷，并已上线 Alexa+ 的动画图标生产流水线。

## 核心方法

- **流水线**：文本 → 生成线稿 → 语义拆分部件 → 矢量化 → 上色 → Lottie 动画。第一步生图质量决定一切，后续无法修复几何缺陷，因此只优化这一步。
- **问题**：高分辨率下线条看似分得开，缩到小画布、按规定粗线宽重绘后就会粘连（stroke crowding）。开源 FLUX.2 [klein]（4B）约 85% 的输出有此问题，提示词约束无效，也没有现成数据可做 SFT。
- **奖励设计**：先用形态学工具标出所有"间隙过窄 / 笔画融合 / 小孔被填实"的区域（阈值都以线宽为单位）；再用一个在 682 个图标、3,836 处人工标注上训练的梯度提升分类器，区分真缺陷和设计本需的紧凑处（如气泡、拐角）。缺陷数加上防退化和概念一致性检查构成奖励。
- **训练**：用 Flow-GRPO 对流匹配模型做 RL，无需任何目标图像。

## 关键结果

- 在独立于奖励模型的 VLM 评审下，合格率从 15.7% 提升到 58.7%（3.7 倍），且能泛化到训练外的新概念。
- 微调模型与验证器均已部署，验证器同时作为设计师终审前的自动质量闸门。

## 为什么值得关注

这是 RLVR 走出数学/代码、落地到图像生成生产系统的典型案例：没有标注数据时，把"设计规范"写成可程序化检查的验证器，就能直接作为 RL 奖励；"几何测量 + 轻量分类器"的组合也给"规则难以穷尽"的奖励设计提供了实用范式。用独立评审防止奖励被钻空子的做法同样值得借鉴。
